# 高考散文阅读讲义

---

## 一、散文基础知识

### 1. 散文与小说的区别

| 体裁 | 核心特征 | 构成要素 |
|------|----------|----------|
| 小说 | 虚构 | 人物、情节、环境 |
| 散文 | 真实 | 线索、主旨、情感、感悟 |

散文的文体特点是"形散神聚"——不论结构思路怎样变化，都围绕中心主旨行文。

### 2. 散文的线索类型

线索是作者将材料串联起来的"红线"或"寄托物"，常见于标题、开头、结尾、过渡段。

| 线索类型 | 说明 |
|----------|------|
| 时间线索 | 按时间推移组织材料 |
| 空间线索 | 按空间转换（移步换景）组织材料 |
| 人物线索 | 以某一人物贯穿全文 |
| 事物线索 | 以某一物件/意象贯穿全文（常见于托物言志） |
| 事件线索 | 以某一事件为核心展开 |
| 情感线索 | 以情感发展变化串联材料（常隐伏于内容中） |

**高考补充：** 高考散文常有**双线索**（明线+暗线），如以游踪为明线、情感变化为暗线。识别双线索是理解复杂散文结构的关键。

### 3. 散文的结构形式

| 结构形式 | 行文思路 |
|----------|----------|
| 静赏式 | 景点概述 → 景点静赏 → 景点联想 |
| 参游式 | 进入景点 → 依次欣赏 → 赏景联想 → 离开景点 |
| 象征式 | 物的描述 → 物的性格 → 由物及人 → 表达志向 |
| 怀念式 | 睹眼前景 → 思从前景（人、事） → 抒怀念情 |
| 叙史式 | 一语统篇 → 追述史实 → 抚今而感慨、抒情 |

**高考补充：** 高考散文常出现**复合结构**——同一篇文章可能前半段是参游式、后半段转为怀念式或叙史式。遇到结构转换时，关注过渡段，它是判断全文思路的枢纽。

### 4. 散文常见的语言风格

| 风格 | 特征 |
|------|------|
| 豪放 | 题材雄心伟业；境界开阔；动词有力度；抒情激越；多用排比、夸张、反复 |
| 柔婉 | 对象纤巧细致；情感细腻缠绵；画面色调柔和；少用排比、夸张 |
| 直露 | 表达感受和观点比较直接 |
| 含蓄 | 托物言志、借景抒情；多用象征、设问、比喻 |
| 质朴 | 语言通俗、口语化；少用复杂修辞 |
| 华丽 | 讲究节奏韵律；多用描写性语言、排比、对偶、引用、用典 |
| 庄重 | 话题严肃；语言凝重；句式整齐、完整而绵长 |
| 诙谐 | 语气轻松幽默；多用夸张、反语、拟人 |

**高考补充：** 高考散文常考**风格辨析**，不只要求识别单一风格，还要求分析风格的变化（如前半段质朴、后半段转为华丽），以及风格与情感之间的关系。

## 二、散文阅读解题步骤

**第一步：速读全文 —— 判类型 → 找线索 → 分层次 → 推主旨**

**第二步：审题 —— 看清问什么（判断母题类型），锁定答题范围**

**第三步：回文取证 —— 启动锚定-验证（详见第四部分）**

**第四步：整理答案 —— 分点作答，合并同类项，规范书写**

## 三、五大题型与六大角度

### 总览

| 五大题型 | 六大角度 |
|----------|----------|
| 概括题 | 内容 |
| 赏析题 | 结构 |
| 作用题 | 主旨 |
| 涵义题 | 情感 |
| 形象题 | 手法 |
| | 人物 |

**题型是"考什么"，角度是"从哪切"。** 一道题可能只用一个角度，也可能需要多角度交叉作答。

### 六大角度分组

| 组别 | 角度 | 特点 | 操作方式 |
|------|------|------|----------|
| **有分类体系** | 手法、结构、人物 | 有明确子分类，可以往下拆 | 识别 → 分类 → 套对应分析框架 |
| **需要锚定-验证** | 内容、主旨、情感 | 没有现成分类，依赖回归原文找句子 | 锚定 → 验证 → 定级 → 止损 |

第一组角度的难点在**识别**（分不清是哪种手法/哪种结构功能），第二组角度的难点在**推理控制**（推断容易滑出原文）。

高考的核心区分度在第二组。手法和结构可以靠背记和训练，内容、主旨、情感的精准提取才是拉开分差的关键。

## 四、锚定-验证操作系统

> **适用场景：** 所有需要从原文提取信息并进行推理的题目。
> 尤其是以"内容""主旨""情感"为角度的概括题、涵义题、作用题。

### 核心原则

**每一条推断都要有 cite（锚点）。没有 cite 的步骤就是跳步，跳步就是丢分。**

### 操作步骤

#### 步骤 0 · 定位文章类型

速读全文后，用主题分类（详见第五部分）快速判断文章属于哪个类型区间，锁定可能的情感方向。这一步的目的是**缩小搜索范围**，不是确定答案。

#### 步骤 1 · 锚定

对任何一条准备写进答案的推断，必须同时找到原文锚点。

- **格式：** [第X段 "原文关键词句"]
- **规则：** 一条推断至少一个锚点；没有锚点的推断不进答案
- **优先级：** 议论抒情句 > 描写句 > 叙述句（议论抒情句最可能直接承载主旨情感）

#### 步骤 2 · 顺势验证

把锚点放回原文前后 2-3 句，检查推断方向：

- **问题 a：** 这个推断是**顺着**这段文字的势走的吗？
- **问题 b：** 如果把推断塞回原文那个位置，作者下一句会不会**自然接**上？
- **判定：** 顺着 → 通过；逆着或需要硬拧 → 过度解读，砍掉或重推

#### 步骤 3 · 多锚点定级

| 锚点数量 | 推断级别 | 说明 |
|----------|----------|------|
| 1 个锚点 | 一级推断 | 字面/直接含义，安全但浅 |
| 2 个不同位置的锚点相互印证 | 二级推断 | 合理推断，可以放心写 |
| 3 个锚点分布在不同段落 | 三级推断 | 结构性/主题性推断，可以作为深层答案 |

**想上三级，锚点数不够就下来。** 这是推理的刹车。

#### 步骤 4 · 止损

如果一条推断需要引入**原文没有出现过**的概念（文化背景、哲学术语、时代语境等）才能成立——**先停**。这条多半是过度解读。

**例外：** 题干明确要求"结合时代背景""联系现实"时，可以适度引入外部知识，但锚点仍须在原文中找到着力点。

#### 步骤 5 · 复盘自检

答完一道题，回头检查：

| 检查项 | 要求 |
|--------|------|
| 每条推断旁边有锚点？ | 有 |
| 锚点放回上下文方向一致？ | 一致 |
| 划掉锚点，推断还站得住？ | 站不住才对（站得住=锚点是装饰=在脑补） |
| 是否引入了原文不存在的概念？ | 没有（除非题干要求） |
| 是否把原文的词偷换成了方向不同的近义词？ | 没有 |

**最后一条是高频陷阱：** 选择题选项常用偷换概念（如把"向往"换成"痛苦"，把"善赏"换成"疾恶如仇"），主观题自己写答案时也容易犯同样的错。

### 锚定-验证在三个角度上的具体应用

#### 用于"内容"角度（概括题）

| 步骤 | 操作 |
|------|------|
| 定位 | 确定概括范围（全文 / 某几段 / 某一段） |
| 锚定 | 逐段找关键句，优先找每段的首句、尾句、议论抒情句 |
| 验证 | 概括的内容是否覆盖了该段的主要信息（不遗漏、不添加） |
| 定级 | 概括题通常只需一级推断（字面概括），不需要深推 |
| 止损 | 如果概括中出现了原文没有的信息，删掉 |

#### 用于"主旨"角度（涵义题 / 作用题 / 标题探究题）

| 步骤 | 操作 |
|------|------|
| 定位 | 用主题分类锁定可能的主旨方向 |
| 锚定 | 找全文的议论抒情句（尤其是结尾段），标记所有直接表达观点/感悟的句子 |
| 验证 | 主旨推断是否和全文各段的内容方向一致 |
| 定级 | 主旨必须是三级推断（多锚点跨段），单锚点支撑的"主旨"多半只是局部情感 |
| 止损 | 主旨概括中最容易出现"升华过度"——如果你的主旨需要借助原文没有的哲学概念才能成立，降级 |

#### 用于"情感"角度（涵义题 / 赏析题）

| 步骤 | 操作 |
|------|------|
| 定位 | 判断情感走向模式（单一 / 递进 / 转折 / 交织），确定要找几层情感 |
| 锚定 | 找情感关键词（动词、形容词、语气词），标记情感变化的转折点 |
| 验证 | 情感标签是否和锚点的用词方向一致（"向往"≠"痛苦"，"敬畏"≠"恐惧"） |
| 定级 | 一级=单处表达的直接情感；二级=多处呼应的贯穿情感；三级=全文层次递进的复合情感 |
| 止损 | 情感类答案最常见的错误是**偷换情感标签**——用一个听起来更"深刻"的词替代原文实际表达的情感 |

## 五、主题分类速查

> **用法：** 速读全文后，先用第一入口判断题材区间，再用第二入口判断情感走向模式。
> 两个入口交叉定位，缩小答题方向的搜索范围。

### 第一入口：题材分类

#### 1. 自然风光（山川、草原、湖海、季节）

- 热爱自然，敬畏自然
- 赞美祖国大好河山
- 向往自由、闲适恬淡的生活
- 人与自然和谐共处 / 生态保护意识

#### 2. 故乡与乡村（故乡、山村、古镇、乡土）

- 乡愁：思乡不得归 / 归乡物是人非
- 怀念童年、怀念故人
- 赞美乡土文化 / 民俗民风
- **复杂情感：** 欣慰（家乡发展进步）与怅然（旧日风貌消逝）并存
- 对城市化进程的反思：精神家园的失落

#### 3. 城市

- 边缘人：无法融入又不能离开
- 城市记忆 / 老城拆迁：怀旧 + 失落
- 城市中的自然：在钢筋水泥里找到慰藉（一棵树、一只鸟）
- 城市里的手艺人 / 小人物：敬意 + 消逝感

#### 4. 怀念（亲人、师长、友人、故人）

- 对人的怀念 / 思念 / 感恩 / 感激
- 对人的敬佩 / 敬畏
- **愧疚：** 子欲养而亲不待；曾经忽视/误解，事后追悔
- 跨越时空的精神交流 / 志同道合

#### 5. 咏物（托物言志）

- 物通常是线索
- 通过对物的描写，表达志向/情感/品格
- 常见方向：坚韧不屈、高洁自守、默默奉献、生命力与顽强
- **高考注意：** 高考咏物散文往往不止于"言志"，还会借物进入文化或哲学层面

#### 6. 叙史与文化

- 借古喻今 / 以古证今
- 民族志 / 地方志：对某地的赞叹、感慨
- 人物类：对历史人物的赞美、敬佩
- 文脉传承、地域文化
- 赞美/感叹中华传统文化精神的赓续
- **高考注意：** 叙史散文的主旨常不在"史"本身，而在"史"与"今"的对照中——要找到作者从历史中提炼出的对当下的思考

#### 7. 感悟与哲思

- 心灵的洗涤、成长
- 对生命意义的思考
- 对人与自然/人与社会关系的哲学反思
- **高考注意：** "感悟"类主题几乎不会单独出现，它总是附着在其他题材上（自然+感悟、怀念+感悟）。如果一篇散文的主题只能概括为"感悟"，说明还没挖到底层

### 第二入口：情感走向模式

| 模式 | 特征 | 识别方法 |
|------|------|----------|
| **单一情感** | 全文贯穿一种基调 | 情感关键词前后一致，无明显转折 |
| **情感递进** | 同一种情感逐层加深 | 每段/每层的情感词强度递增（喜欢→热爱→敬畏） |
| **情感转折** | 前后情感发生方向性变化 | 有明显的转折词/转折段（"然而""可是""直到……才"） |
| **复杂交织** | 多种情感同时并存，不可拆分为先后 | 同一段内出现方向不同的情感词（欣慰与怅然、敬佩与惋惜） |

**操作要点：**
- 单一情感 → 答题只需写一层
- 情感递进 → 答题要写出层次（从……到……再到……）
- 情感转折 → 答题要写出转折点及前后变化
- 复杂交织 → 答题必须把多种情感都写出来，不可只答其一

## 六、题型详解

### 题型一：概括题

#### 答题格式

**（时间/地点），人物 + 事件（起因、经过、结果）**

#### 高考要点

- 概括题的核心角度是**内容**，启动锚定-验证的"内容"路径
- 高考概括题常要求概括**多个层次**的内容（如"文章围绕XX写了哪几件事""梳理作者的情感变化"）
- **逐段锚定**：每段找一个关键句做概括锚点，避免遗漏
- 概括题不需要深推，保持在一级推断（字面概括），不要"升华"

### 题型二：赏析题

赏析题的核心角度是**手法**，按手法类型分为四类：

#### 1. 修辞手法赏析

| 修辞手法 | 答题要点 |
|----------|----------|
| 比喻 | 指出本体、喻体 → 相似点 → 生动形象地描绘了……特点 → 表达了……情感 |
| 拟人 | 赋予……以人的情态/动作 → 生动形象地描写了……特点 → 表达了……情感 |
| 排比 | 增强语势和节奏感 → 有力地表现了……特点 / 强化了……情感 |
| 对比 | 将A与B对比 → 突出A的……特点 → 表达了……情感 |
| 夸张 | 强调了……特点 → 表达了……情感 |
| 反问 | 加强语气 → 强调了……/ 表达了……情感 |
| 设问 | 引人思考 → 强调了……特点 |
| 反复 | 强调突出…… → 一唱三叹，加强节奏感和抒情效果 |
| 对偶 | 句式整齐，音节匀称 → 表意凝练，具警策之美 |
| 双关 | 语意含蓄，一语双关 → 表层义……，深层义…… |
| 借代 | 用……代替…… → 突出特征，使语言简洁精练 |
| 通感 | ……觉转为……觉 → 丰富感受，加强表达效果 |
| 引用 | 增强说服力和文化底蕴 → 丰富文章内容 |
| 反语 | 说反话 → 讽刺/幽默效果，增强批判性 |

#### 2. 描写手法赏析

| 描写对象 | 描写手法 | 答题要点 |
|----------|----------|----------|
| 人物 | 语言、动作、心理、神态、外貌 | 通过……描写，表现出人物的……状态/心理/性格 |
| 环境 | 自然环境 | 烘托……氛围，衬托人物……心情 |
| | 社会环境 | 交代……背景，暗示……主题 |
| 描写角度 | 正面 / 侧面 | 正面直接表现；侧面烘托、反衬 |
| 描写方式 | 工笔细描 / 白描 | 工笔：淋漓尽致；白描：简洁传神 |
| 感官角度 | 视觉、听觉、嗅觉、味觉、触觉 | 多感官结合，立体展现 |
| 写景角度 | 远近、高低、动静、虚实 | 远近结合/动静结合/虚实结合 → 使景物更生动丰富 |

#### 3. 表现手法赏析

| 手法 | 内涵 | 艺术效果 |
|------|------|----------|
| 对比 | 把差异明显的双方安排在一起 | 突出对立，给人鲜明印象 |
| 象征 | 借具体形象表现抽象概念 | 立意高远，含蓄深刻 |
| 联想和想象 | 由此物想到彼物 / 创造新形象 | 丰富内容，增强表现力 |
| 衬托 | 正衬 / 反衬 | 突出主体，使形象鲜明 |
| 抑扬 | 先抑后扬 / 先扬后抑 | 形成反差，突出中心 |
| 虚实结合 | 以实衬虚 / 以虚衬实 | 突出本质特征，拓宽意境 |
| 以小见大 | 从小事件/小细节切入 | 小中见大，深化主题 |
| 铺垫 | 为后文情节预先布置 | 渲染气氛，增强吸引力 |
| 伏笔照应 | 前文暗示，后文呼应 | 构思精巧，结构严密 |
| 借景抒情 | 带感情去描写景物 | 情景交融，含蓄蕴藉 |
| 托物言志 | 借物的特性表达志向 | 含蓄表达，意蕴深远 |

#### 4. 句式与语言特点赏析

| 句式类型 | 特点 | 作用 |
|----------|------|------|
| 长句 | 用词多、结构复杂 | 表意严密，内容丰富 |
| 短句 | 用词少、结构简单 | 节奏短促，生动有力 |
| 长短结合 | | 错落有致，变化多姿 |
| 整句（对偶/排比） | 整齐匀称 | 节奏和谐，富有气势 |
| 散句 | 参差错落 | 灵活自由，自然舒缓 |
| 整散结合 | | 整齐中见变化，急促中有舒缓 |

**赏析题答题通用格式：**

> **(1) 指出手法（用了……手法 / ……词）**
> **(2) 写出内容（写出了……）**
> **(3) 分析效果（表现了……特点 / 突出了……）**
> **(4) 点明情感（表达了……情感 / 揭示了……主旨）**

### 题型三：作用题

作用题需要从**内容**和**结构**两个维度回答，有时还涉及手法维度。

#### 1. 句段作用

| 位置 | 结构作用 | 内容作用 |
|------|----------|----------|
| 开头段 | 总领全文；引出下文；为下文铺垫/埋伏笔；设置悬念 | 开篇点题，点明主旨；奠定感情基调；营造氛围；引起读者兴趣 |
| 中间段 | 承上启下（过渡）；照应标题/前文；为下文铺垫；推动行文发展 | 承接上文……内容，开启下文……内容；转换写作角度/维度 |
| 结尾段 | 总结全文；照应开头/标题，使结构完整 | 点明中心，深化/升华主题；戛然而止，引人深思；出人意料，情理之中 |

**高考补充——中间段的特殊类型：**

| 类型 | 作用 |
|------|------|
| 引用性材料（诗句/典故/传说） | 丰富内容，增强文化底蕴；含蓄引出/印证观点；增加诗意/传奇性 |
| 插入性材料（回忆/联想） | 与上下文构成对比/映衬/递进；对主旨起强化作用；宕开一笔形成波澜 |
| 反复出现的句子 | 内容上强调主旨/强化情感；结构上交代线索/前后呼应；一唱三叹之效 |

**高考关键提醒：** 回答"作用"类题目时，不能只说"深化了主题"——**必须说清楚"从什么变成了什么"**。锚定-验证在这里的用法是：你说"过渡"，要锚定上文写的是什么、下文写的是什么；你说"深化主题"，要锚定主题从哪一层推进到了哪一层。没有具体内容的"作用"分析就是空话。

#### 2. 标题作用

| 角度 | 可能的作用 |
|------|-----------|
| 内容 | 点明写作对象/事件/地点/时间 |
| 结构 | 是全文线索，贯穿始终 |
| 主旨 | 揭示/暗示文章主旨 |
| 情感 | 表达作者情感态度 |
| 手法 | 运用双关/象征/比喻/化用诗句等 |
| 效果 | 引起读者兴趣/悬念/联想 |

**高考补充：** 高考标题探究题常要求分析**标题的多层含义**（表层义 + 深层义），或比较**不同标题的优劣**。操作方法：用锚定-验证的定级系统——表层义=一级（字面），深层义=二级或三级（需要多锚点支撑）。

#### 3. 叙述方式及其作用

| 叙述方式 | 作用 |
|----------|------|
| 顺叙 | 层次清晰，自然顺畅 |
| 倒叙 | 造成悬念，引人入胜 |
| 插叙 | 补充说明，丰富内容，使情节更完整 |
| 补叙 | 对上文补充解释，造成叙事波澜 |

#### 4. 人称作用

| 人称 | 作用 |
|------|------|
| 第一人称 | 真实感、亲切感；便于直接抒情；常作为线索 |
| 第二人称 | 便于抒情，拉近距离，增强亲切感；用于物则有拟人效果 |
| 第三人称 | 客观灵活，不受时空限制，便于多角度描写 |

**高考补充：** 高考常考**人称转换**的效果（如从第三人称转为第二人称），分析时要锚定转换发生的具体位置，说明转换前后情感表达方式的变化。

### 题型四：涵义理解题

#### 答题公式

**表层（字面义） + 深层（主旨 + 情感/感悟）**

#### 1. 词语涵义

**一词多段（同一个词在不同段落出现）：**
- 共同表达了……情感
- 第 X 段：……（语境义），表达了……情感
- 第 Y 段：……（语境义），表达了……情感

**一词一段：**
- 内容：语境义（用自己的话解释）
- 深层：主旨意
- 深层：作者情感

**有前后对比时：** 深层义往往是"以前……，现在……"的变化

#### 2. 句子涵义

**内看（句子内部）：**
- 找句中关键词 → 解释关键词含义
- 看是否使用修辞/手法 → 还原为直白意思
- 看句子结构（单句/复句） → 逐层分析

**外联（句子外部）：**
- 联位置：总领句看下文，总结句看上文，过渡句看前后
- 联前后句：从上下文推断特定含义
- 联主旨：结合全文主旨理解深层含意

#### 高考关键提醒

涵义题是锚定-验证最核心的应用场景。**每一层含义都必须有锚点支撑：**
- 表层义的锚点 = 句子/词语本身
- 深层义的锚点 = 上下文中与之呼应的其他句子
- 如果"深层义"找不到第二个锚点来印证，它可能只是你的脑补

### 题型五：形象题

形象题考查的是对**人物形象**或**物象**的分析。

#### 1. 人物形象分析

**答题格式：**

> **下定论（概括形象特点）+ 举证（概括事件/引用细节）+ 总结（表现了……品质/性格）**

**概括人物形象的三个角度：**
- 从事件中概括（做了什么事 → 体现什么品质）
- 从描写中概括（语言/动作/心理/神态 → 体现什么性格）
- 从议论抒情中概括（作者或他人对人物的评价 → 直接点明特点）

**次要人物的作用：**
- 引出主要人物，推动情节发展
- 侧面烘托/反衬主要人物
- "我"作为次要人物：增强真实感 + 线索作用
- 暗示/揭示文章主旨

#### 2. 物象分析

**概括物象特点（由表及里）：**
- 第一步：外在特征（形态、色泽、习性）
- 第二步：内在品格（内涵、精神、象征意义）
- 第三步：作者情感（借此物表达了什么情感/志向）

**物象作用分析：**

| 物象类型 | 内容主旨方面 | 艺术构思方面 |
|----------|--------------|--------------|
| 主要物象 | 承载主旨，揭示"神" | 常为全文线索 |
| 次要物象 | 充实内容，深化主旨 | 对比/衬托/类比主要物象 |

#### 高考关键提醒

人物形象题的答案要**锚定具体细节**，不能只给标签。"坚韧不拔"是标签，"在……情况下做了……事"才是锚点。标签+锚点=完整答案。

## 七、散文情感归类速查

### 叙事散文（写人）

| 写作对象 | 常见情感方向 |
|----------|-------------|
| 写老师 | 感恩、怀念、爱戴、敬佩 |
| 写亲人 | 感恩、歌颂亲情、传承、怀念、**愧疚**（高频） |
| 写伟人 | 歌颂精神品质、赞美、敬佩 |
| 写平凡人 | 赞美质朴/坚守/奉献；以小见大→作者认知和思考 |
| 写自己 | 自我审视、成长顿悟、突破蜕变；"过去的我"与"现在的我"对比 |
| 特殊群体 | 非遗匠人→技艺+传承；战士→英勇+牺牲；基层干部→奉献+振兴；普通劳动者→尊严+坚守 |

### 写景散文

| 写作对象 | 常见情感方向 |
|----------|-------------|
| 自然风景 | 热爱、敬畏、向往自由 |
| 故乡 | 乡愁、怀念、**复杂情感**（欣慰与怅然并存） |
| 城市 | 边缘感、怀旧失落、城市中寻找慰藉 |
| 土地与人 | 赞美淳朴、歌颂劳动 |

### 状物散文

| 手法 | 常见方向 |
|------|----------|
| 托物言志 | 坚韧不屈、高洁自守、默默奉献、生命力与顽强 |
| 借物喻人 | 指明此物象征/喻指哪类人及其品质 |

### 回忆性散文

- 时光流逝，怀念青春年华/过去的美好
- 对他人/自己的美好祝愿、期望
- 对未来生活的畅想

## 附录：答题规范

### 通用答题步骤

1. **审题**：判断题型（概括/赏析/作用/涵义/形象），锁定角度
2. **回文**：启动锚定-验证，找到锚点
3. **组织**：按角度分点，每点有锚点支撑
4. **书写**：规范表述，分点清晰

### 分值与要点对应

| 分值 | 通常要点数 |
|------|-----------|
| 2-3 分 | 1-2 个要点 |
| 4 分 | 2 个要点 |
| 6 分 | 3 个要点 |

**要点之间不能交叉重复——合并同类项。**

### 高考主观题答题模板

**概括题：** （时间/地点）+人物+事件

**赏析题：** 手法 + 内容 + 效果 + 情感

**作用题：** 内容上…… + 结构上…… +（手法上……）

**涵义题：** 表层义 + 深层义（主旨/情感）

**形象题：** 形象特点 + 具体事件/细节 + 品质/性格
