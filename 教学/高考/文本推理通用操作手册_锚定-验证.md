# 文本推理通用操作手册（锚定-验证法）

> **适用对象：** 语文阅读推理题（散文 / 小说 / 论述文 / 文言文），跨文体的通用操作工具
> **核心主张：** 每一步推断都要有文本依据（锚定），放回上下文看方向一致（验证）
> **使用方式：** 先看适用范围，再学五步骨架，按题型查具体操作，最后用自检清单
> **状态：** 2026-04-18 起草，待 Emrys 课堂实测后修订

---

## 一、适用范围

**可以用（主工具）：**

- 阅读选择题（散文 / 小说 / 论述文 / 文言文选择）
- 散文 / 小说主旨题
- 散文 / 小说情感赏析题
- 作用题（段落 / 句子 / 意象 / 情节）
- 文言文翻译与简答

**辅助使用（不是主工具）：**

- 文言文字词判断——**语法先行，锚定辅助**（语法做判断，锚定做验证）

**不适用：**

- 诗歌鉴赏（意象是压缩包而非推理链，锚定会把诗读死）
- 议论文立论升维（三级·诘需要跨层跳跃，锚点会压制跳跃）
- 纯情感体验（读者自己的感受，不是答题推断）

---

## 二、核心骨架（五步）

| 步骤 | 动作 | 判据 |
|:-:|:--|:--|
| 0. 复述 | 用一句话说清题目问的是什么 | 别审错题 |
| 1. 锚定 | 每条推断旁写出 [第X段 / 第X句 "原文"] | 每一步都有文本依据 |
| 2. 顺势验证 | 推断放回原文前后2–3句，看方向一致吗 | 顺着文本势推出 = 合理；逆着势硬拧 = 过度 |
| 3. 多锚点定级 | 1 锚点 = 一级；2 锚点 = 二级；3 锚点跨段 = 三级 | 锚点越多 / 分布越广，推断越扎实 |
| 4. 止损 | 需要引入原文没有的概念才成立？——停 | 不能凭空加公理 |
| 5. 复盘 | 划掉锚点，推断还站得住吗？——站得住 = 锚点是装饰 | 反证法 |

**术语适配：**

- 理科脑 / 数学强学生（子穆型）：用"锚点"、类比"数学证明引用定理"
- 初中生 / 文科生 / 家长：换成"依据"
- 纯线性思维学生（鼎宸型）：锚定-验证可用，但要配合"比较判断 vs 绝对判断"（见 `09_course_positioning.md`）

## 三、五种题型的具体操作

### 1. 选择题

- 对每个选项逐一锚定，选"锚点最不支持"的那项
- **配合"比较判断 vs 绝对判断"**——不是选"完全对的一项"，是选"最错的一项"
- 死扣字面匹配的学生（鼎宸型）先从**判对的选项反射判错的选项**（镜像方法，见 `09_course_positioning.md`）

### 2. 文言文字词

- **先做语法判断**——看词性、句法位置、前后接什么
- **后做锚定验证**——把语法判断放回语境看是否说得通
- 语法和语境冲突时以语境为准，但**先有语法判断作为假设**再验证
- 锚定在文言字词判断里是二等工具，不是主工具

### 3. 主旨题

- 从结尾段 + 贯穿全文的关键词找锚点
- 多锚点交叉定级（3 锚点跨段 = 三级推断，最扎实）
- **止损：** 主旨不能脱离文本本身提供的信号，不要写"体现了中华民族的伟大"这种没锚点的大词

### 4. 情感赏析题

情感锚点六类：

| 类型 | 例子 |
|:--|:--|
| 直接情感词 | "泪流满面"、"沉默"、"心如刀绞" |
| 动作描写 | 紧握拳头、低头、转身 |
| 环境描写 | 天灰蒙蒙、雨声、落日 |
| 语言选择 | 用词的感情色彩（"踽踽独行" vs "慢慢走"） |
| 细节安排 | 放大 / 省略了什么 |
| 节奏变化 | 句子长短、重复、停顿 |

**操作：**

- 不是从"我感觉作者很伤心"下判断，是**从文本信号推断情感**
- 单一锚点判断容易偏，至少两类锚点交叉
- **止损：** 情感推断不能走出文本提供的信号范围——"因为作者小时候可能经历过什么"这类脑补直接砍

### 5. 作用题

**三种锚点都要找：**

| 锚点类型 | 答什么 |
|:--|:--|
| 内容锚点 | 这段 / 这句 / 这个意象具体写了什么 |
| 结构锚点 | 位置在哪里、和前后段的关系、结构功能（铺垫 / 过渡 / 照应 / 枢纽） |
| 主题锚点 | 和全文中心 / 情感走向的关系 |

**三类锚点合起来才是"作用"的完整说明。**

- **止损：** 不要写"深化主题""升华中心思想"这种没有锚点的万能话
- **判据：** 如果你的"作用"结论可以套用到本文任何一段，说明你没有真的在做这道题

## 四、和三级框架（读 / 拆 / 诘）的接口

**锚定-验证服务于一级·读 + 二级·拆**——帮学生在文本内部做扎实的理解和切割。

**三级·诘需要暂时脱锚**——诘是跳出命题问边界 / 反例 / 前提，这时候要允许学生暂时离开文本锚点。**但跳完要回来**，确保跳跃不是完全脱节的脑补。

| 题型 | 主要用哪层 | 锚定-验证的角色 |
|:--|:--|:--|
| 阅读选择题 / 主旨 / 情感 / 作用 | 读 + 拆 | 全程主工具 |
| 议论文立论升维 | 诘 | 不是主工具，见议论文手册第三部分 |
| 作文论据展开 | 拆 | 锚点 = 经验 / 知识的具体颗粒，类比但不同 |

---

## 五、失效信号

什么时候该停用锚定-验证：

1. 题目进入诘层（立论升维、边界审问）
2. 题目是诗歌鉴赏
3. 学生还没过文体入口台阶（硕硕层级）——连入口都没进，找不到锚点

---

## 六、自检清单

做完一道题后，用这张表自检：

- [ ] 每条推断旁边都写了原文锚点？
- [ ] 锚点放回上下文，推断方向和原文一致？
- [ ] 如果划掉锚点，推断还站得住吗？（站得住 = 脑补警报）
- [ ] 有没有引入原文不存在的概念？
- [ ] 有没有把原文的词偷换成另一个意思相近但方向不同的词？
