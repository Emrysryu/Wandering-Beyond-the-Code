# 七、落盘：三件工具，离开教室也带得走

- **替换测试**——为什么用这个词，不用那个词？
- **联想场分析**——这个词在我脑子里触发了什么画面、温度、声音？
- **位置 / 验证**——它的位置参与了表达吗？我的判断和上下文吻合吗？

考试里的"炼字题"和"词语赏析题"，本质都在问同一个问题：

**你能不能感受到这个词和别的词之间的边界？**
