# 高考记叙文·故事设计讲义

> **讲义说明：**
> 本讲义用于高考记叙文教学。主体内容学生阅读，**灰色引用框内为教师批注**，课堂讲解时按需展开。
> 
> 讲义融合三条理论脉络：荣格原型 / 坎贝尔《千面英雄》"英雄之旅" / 麦基《故事》；落点在《此刻，我必须说》等北京高考记叙文题的考场实战。
> 
> 三篇经典范文（《赤兔之死》《伤心儿女》《与科技相遇》）+ 一篇高考标杆文（《此刻，我必须说》1 号文）+ 两篇学生作品（《因为热爱，所以奔赴》《又见灯塔》）分别嵌入对应章节做示范拆解。

## 一、记叙文的本质

### 1. 初中 vs 高中：记叙文的跃升

初中阶段的作文分两类：

- **写实文 = 非虚构写作**：你真实经历过的事情
- **想象文 = 虚构写作**：科幻、童话、故事新编

高中的记叙文**不再是这两类的任何一个**，而是——

> **高中记叙文 = 微小说 或 纪实文学**

这句话里藏着一个被很多学生忽略的关键：**高中记叙文要求你"讲好一个故事"，不是"记录一件事"**。

"记录一件事"只要交代清楚时间、地点、人物、起因、经过、结果就合格了。
"讲好一个故事"要求**人物在变化中完成转变**。没有变化，就没有故事；只有描写。

> **教师批注：** 这一条是整套讲义的骨——如果学生没接受"高中记叙文是小说或纪实"这个定位，后面讲什么都是空的。大部分学生卡住的第一层就是这里：他们以为高考作文就是"真情实感地写一件亲身经历"，结果写出一篇"周记"，自然拿不了高分。可以举反例：如果只是"真情实感记录一件事"，那《此刻，我必须说》的一类上标杆文为什么要精心设计五四青年、外卖员副处长这种完全虚构的"我"？

### 2. 讲故事是一门手艺

讲故事不是天赋，是可以被训练的**手艺**。全世界研究这门手艺的人里，有三个人的工作最值得我们借用：

- **心理学家卡尔·荣格**：提出**原型**理论——人类集体潜意识里有**十二种人格原型**
- **神话学家约瑟夫·坎贝尔**：研究全世界神话后提出**英雄之旅**——所有故事的底层骨架
- **编剧教师罗伯特·麦基**：把上述理论应用到现代叙事，写出《故事》这本被全世界小说家和编剧奉为圣经的书

这三个名字你不一定要记住。**但他们合起来给出的方法论，能把你的记叙文从"平淡记录"提升到"一个真正的故事"。**

> **教师批注：** 这三个名字对学生来说是权威信号——让他们知道后面讲的东西不是"老师自己编的应试套路"，是被好莱坞、被全世界讲故事的人验证过的底层机制。对铧阳这种高势能学生尤其有效——她会把这种权威感接住，愿意认真学。

## 二、故事的模板

### 1. 英雄之旅——所有好故事的底层骨架

坎贝尔研究了全世界的神话故事，发现一件惊人的事：**从古希腊到北欧，从印度到美洲印第安人，所有"英雄"的故事几乎都遵循同一个结构。**

他把这个结构叫做**英雄之旅**：

```
一位英雄从日常的世界勇敢地进入超自然的神奇区域：
在那里遇到了传奇般的力量，取得了决定性的胜利；
英雄带着这种力量从神秘的历险之旅中归来，赐福于他的人民。
                                           ——约瑟夫·坎贝尔，《千面英雄》
```

**这个结构分五个阶段：**

| 阶段 | 核心动作 |
|------|---------|
| **召唤** | 平凡世界中的平凡人 → 冒险的召唤 / 拒绝召唤 / 成为受害者 |
| **启蒙** | 踏入超自然世界 → 超自然援助 → 跨过阈限 → 英雄重生 |
| **考验** | 考验之路 → 女神与诱惑 → 帮助者出现 |
| **和解** | 与神（支持者）和解，尊奉 → 获得恩赐 |
| **回归** | 拒绝回归 / 主动或被动逃脱 → 带着恩赐归来 |

> **教师批注：** 学生一听"超自然""神""英雄"容易跑偏，以为要写魔幻。关键要讲清：**"超自然世界"不等于魔法，而是"非日常的情境"**——面试、比赛、冲突现场、突发事件、重大抉择、家族秘密被揭开的那一刻……这些都是"超自然世界"在现实中的形态。后面《伤心儿女》那篇会具体讲这一点。

### 2. 压缩版——起承转合

英雄之旅五阶段对高中生来说复杂了点。我们把它压缩成**起承转合**：

```
起（召唤）：特殊事件开始。主角进入一个不寻常的情境
↓
承（启蒙+考验）：面对困境。压力加深，主角内心挣扎
↓
转（考验+和解）：获得帮助，突破阈限。**关键时刻爆发**
↓
合（回归）：获得成功 / 获得收获。主角带着改变归来
```

**记住：**
- **起**不是"开头"，是**召唤**——把主角推进一个他原本不在的情境
- **承**不是"中间"，是**压力**——让主角越来越难
- **转**不是"转折"，是**爆发**——在最大压力下做出选择
- **合**不是"结尾"，是**归来**——主角已经不是起的那个主角了

> **教师批注：** 起承转合中学生都听过，但通常被理解成"开头-发展-转折-结尾"四个位置。用英雄之旅重新诠释之后，每个位置都有了叙事功能——这是从"结构模板"升级到"变化机制"的关键。**重点讲"转"=爆发点=评分标准里"此刻"的真身。** 很多学生的"此刻"放在开头，其实是把"起"和"转"搞混了。

### 3. 六大故事母题（选材地图）

坎贝尔之后，研究者发现人类讲的故事虽然千变万化，但**母题就那么几种**：

- **成长母题**（射雕英雄传、西游记中的唐僧）—— 从不成熟到成熟
- **对抗母题**（基督山伯爵的复仇）—— 主角 vs 某种强大力量
- **寻找母题**（浮士德、指环王）—— 追寻一个目标 / 一个答案
- **复仇母题**（基督山伯爵）—— 不义的事情需要被清算
- **爱情母题**（灰姑娘）—— 两个灵魂的相遇
- **人物原型母题**（关羽的忠义）—— 一个人物承载一种文化价值

高考题材里最常见的是**成长母题**（《此刻，我必须说》1 号文就是），其次是**对抗母题**（5 号、8 号的五四 / 巴黎和会题材）。

> **教师批注：** 母题作为"选材地图"是给学生降低开头门槛用的——他们不用"从零发明一个故事"，可以**先选母题再找素材**。对鼎宸、子迅这种"不知道写什么"的学生特别有效。

### 4. 《赤兔之死》——起承转合与对抗母题的典范

**2001 全国卷高考题（话题：诚信）**，要求以"诚信"为话题写文章。

一位考生用**文言叙事**写了《赤兔之死》——把《三国演义》里被忽视的赤兔马作为主角，以它的死讲"诚信"。这篇拿了满分，成为中国高考史上最著名的范文之一。

**原文：**

> **赤兔之死**
> 
> 建安二十六年，关羽走麦城，兵败遭擒，拒降，为孙权所害。其坐骑赤兔马为孙权赐予马忠。
> 
> 一日，马忠上表：赤兔马绝食数日，不久将亡。孙权大惊，急访江东名士伯喜。此人乃伯乐之后，人言其精通马语。
> 
> 马忠引伯喜回府，至槽间，但见赤兔马伏于地，哀嘶不止。众人不解，惟伯喜知之。伯喜遣散诸人，抚其背叹道："昔日曹操做《龟虽寿》，'老骥伏枥，志在千里。烈士暮年，壮心不已'，吾深知君念关将军之恩义，欲从之于地下。然当日吕奉先白门楼殒命，亦未见君如此相依，为何今日这等轻生，岂不负君千里之志哉。"
> 
> 赤兔马哀嘶一声，叹道："予尝闻，'鸟之将死，其鸣也哀；人之将死，其言也善。'今幸遇先生，吾可将肺腑之言相告。吾生于西凉，后为董卓所获，此人飞扬跋扈，杀少帝，卧龙床，实为汉贼，吾深恨之。"
> 
> 伯喜点头，曰："后闻李儒献计，将君赠予吕布，吕布乃天下第一勇将，众皆言，'人中吕布，马中赤兔'想来不负君之志也。"
> 
> 赤兔马叹曰："公言差矣。吕布此人最是无信，为荣华而杀丁原，为美色而刺董卓，投刘备而夺其徐州，结袁术而斩其婚使 '人无信不立，与此等无诚信之人齐名，实为吾平生之大耻！后吾归于曹操，其手下虽猛将如云，却无人可称英雄。吾恐今生祗辱于奴隶人之手，骈死于槽枥之间。后曹操将吾赠予关将军，吾曾于虎牢关前见其武勇，白门楼上见其恩义，仰慕已久。关将军见吾亦大喜，拜谢曹操。操问何故如此，关将军答曰：'吾知此马日行千里，今幸得之，他日若知兄长下落，可一日而得见矣。'其人诚信如此。常言道：'鸟随鸾凤飞腾远，人伴贤良品自高。'吾敢不以死相报乎？"
> 
> 伯喜闻之，叹曰："人皆言关将军乃诚信之士，今日所闻，果真如此。"
> 
> 赤兔马泣曰："吾常闻不食周粟之伯夷、叔齐之高义。玉可碎而不可损其白，竹可破而不可毁其节。士为知己而死，人因诚信而存，吾安肯食吴粟而苟活于世间？"言罢，伏地而亡。
> 
> 伯喜放声痛哭，曰："物犹如此，人何以堪。"后奏于孙权。权闻之亦泣："吾不知云长诚信如此，今忠义之士为吾所害，吾何面目见天下苍生？"
> 
> 后孙权传旨，将关羽父子并赤兔马厚葬。

**起承转合拆解：**

- **起（召唤）**：赤兔马绝食数日将亡，孙权召来伯喜。"特殊事件"启动——一匹将死的马，需要被"翻译"。
- **承（启蒙+考验）**：伯喜对赤兔马的第一层解读是"念关将军之恩义，欲从之于地下"——这是**表层**动机。赤兔马自己说出真正的过往：生于西凉、被董卓所获、仰慕关羽的诚信。压力层层加深。
- **转（考验+和解）**：赤兔马说出核心判断——"人无信不立，与此等无诚信之人齐名，实为吾平生之大耻"。这是**爆发点**。它不是为关羽殉死，是因为关羽身上有它一生追求的"诚信"。**它在以死承载一个价值。**
- **合（回归）**："玉可碎而不可损其白，竹可破而不可毁其节。士为知己而死，人因诚信而存，吾安肯食吴粟而苟活于世间？"——**一语明志。** 赤兔马死了，但把"诚信"这个价值刻进了故事。

**母题定位：对抗母题**——赤兔马对抗的是"苟活"的诱惑，胜利是"宁死不食敌粟"。

> **教师批注：** 这一篇的关键教学点是**让学生看见"起承转合"怎么在一篇文言叙事里工作**。伯喜和赤兔马的对话不是闲笔——它是**把赤兔马内心挣扎外化**的工具。赤兔马一个动物，怎么展示它的内心？只能靠对话。这就是人物塑造里"深层本性和外部面貌通过冲突来揭示"的技巧（见第三章）。
> 
> 另一个关键：**这篇文言化用《出师表》《马说》《岳阳楼记》等文章的句式**——"人无信不立""玉可碎而不可损其白"等。这种文化资源的调用让这篇文章立刻具备"底蕴",而不是靠空大词堆砌。**这是学生可以学的动作：不是生造金句，是从文化资源里借力。**

## 三、人物塑造

### 1. 人物塑造 ≠ 人物

麦基在《故事》里给了一个重要的区分：

> **人物塑造**（Characterization）= 通过观察、记录获知的**外壳**（外貌、职业、口头禅、习惯）
> **人物**（True Character）= 压力下做出选择时揭示的**真实本性**

**一个关键原则：人物的内心绝不能和外表一模一样。**

- 看起来勇敢的人，内心可能怯懦
- 看起来严厉的外婆，内心可能最温柔
- 看起来愤世嫉俗的人，内心可能最理想主义

故事的核心乐趣就在于：**外壳被压力击破，内在本性被揭示出来。**

### 2. 真正的选择是两难之选

> **人物性格真相是人处于压力下做出选择时揭示的。**
> **压力越大，揭示越深，也越能真实地体现人物本性。**
> 
> **真正的选择是两难之选：**
> **一是不可调和的"两善取其一"**
> **二是"两恶取其轻"**

**这一条是整套方法论的心脏。**

什么叫"两善取其一"？比如：
- 坚持原则（善）vs 保护朋友（善）——无法兼得
- 个人理想（善）vs 家庭责任（善）——无法兼得

什么叫"两恶取其轻"？比如：
- 沉默（恶：违背良心）vs 举报朋友（恶：伤害友谊）
- 说谎安慰将死之人（恶：不诚实）vs 说实话（恶：伤害对方）

**如果一个故事里的选择不是两难，那就没有故事——因为主角"选"的其实不是"选择"，是"显然该做的事"。**

> **教师批注：** 这一条直接解决《此刻，我必须说》的切题问题。评分标准说"必须≠想说/要说/可以说，意味着不得不说，非说不可"——这个"不得不"的本质就是两难之选下的决断。课上可以让学生用"两难四象限"检查自己的构思：说要付代价吗？不说要付代价吗？两个代价都不大 → 不切题。

### 3. 人物塑造五步操作法

1. **铺陈出主人公的人物塑造特征**——外壳（职业、外貌、习惯、口头禅）
2. **在他选择采取某个行动的过程中揭示其真实本性**——第一次让本性露一角
3. **深层本性和人物的外部面貌发生冲突，即使不完全矛盾，也要互成对照**——建立张力
4. **在揭露了人物的内在本性之后，给他施加越来越大的压力，要他做出越来越困难的选择**——递增压力
5. **待到故事高潮来临，这些选择已经深刻地改变了人物的人性**——人物弧光完成

**这五步就是一个人物从"扁平"变成"立体"的过程。**

### 4. 《与科技相遇》——人物塑造五步的典范

**2017 西城一模**（记叙文，题目：与科技相遇）。十一学校某位学生的标杆文：

> **与科技相遇**
> 
> 看着眼前的少年安静地吃着自己最拿手的番茄炒蛋，微笑就忍不住爬上了她的嘴角。这棕褐色的头发、瘦削的面颊，甚至左眉峰上的一颗黑痣都让她再熟悉不过了。
> 
> 她无法想象如果没有克隆技术，她将怎样活下来。14 年前那场惨烈的车祸夺去了她挚爱的独子充满朝气的生命。太平间中那单薄的身躯孤独的浸没在冷酷的白色中，将她的心也埋在了那里。她永远不能忘记自己当时无法遏制的悲伤，因此，当几个医生秘密地找到她，问她是否愿意参与到克隆试验，帮她再造一个一模一样的儿子时，她毫不犹豫地同意了。她想：宝贝英华，你要复活了，对吗？取死亡英华的体细胞导入去核卵母细胞中，经早期胚胎培养注入子宫中……不到 1 年时间，克隆英华出生了！看着那个长相、哭声与英华一模一样的婴儿，她痴痴地笑了："英华，你又活了。"
> 
> "妈，我不爱吃番茄炒蛋，你又忘了？"她被少年愤愤的声音从回忆中拉出，一阵惶惑、失落袭上心头。"妈记得 14 年前你就……""又是 14 年前！我说了多少遍了，我是我，我不是那个英华！""妈知道你 14 年前就最爱吃番茄炒蛋啊，怎么……""那个死了的不是我！"褐发少年气愤地摔了筷子，跑回屋中反锁上了门。
> 
> 其实他讨厌的并不仅仅是一盘番茄炒蛋，他讨厌自己的长相，自己被母亲莫名其妙地冠以各种爱好、特质，更讨厌他们本身的主人——那个死了的原来的英华。还记得刚上小学的时候，那时喜欢足球的他被母亲硬拉着来到了篮球课，他哭闹着，却拗不过母亲口中不停地絮叨"英华 14 年前就喜欢篮球，妈记得，妈记得……"四周围过来的看热闹的小朋友嘻嘻哈哈地笑着。泪眼婆娑中，他依稀听到不知是谁，小声地说道："你知道吗，他是个克隆人诶！""克隆人？那是什么？"  就是一个死了的人的复印件啊。"复印件？从那以后，他渐渐知道了自己与别人是有些不同的。这么多年他一直在那个原来的英华的阴影中，卑微地活着。被母亲以"妈记得，14 年前你就……"为由，逼迫着做着各种不喜欢的事情，被同学以拙劣的复印件而嘲笑。尽管生物课本告诉他表现型是基因和环境共同决定的，即使有着同样的基因，他也是一个不同的个体，然而，比科技更难违背的却是人心。
> 
> 呜呜咽咽地哭了一晚上，他决定要成为一个有独立人格的人。提起笔，他写下一封长信：
> 
> 妈，科技是为人性服务的，而不能违拗了人性。它成全了你的爱，也请你成全我独立的心……

**人物塑造五步拆解：**

**第一步·铺陈外壳：** "棕褐色的头发、瘦削的面颊，甚至左眉峰上的一颗黑痣"——少年的外壳就是那个死去的英华的复制品。**外壳决定了他的困境。**

**第二步·行动揭示本性：** "妈，我不爱吃番茄炒蛋，你又忘了？"——第一次让他的本性露一角：他不是英华，他有自己的喜好。

**第三步·深层本性与外部面貌对照：** 他**长得像英华**（外壳），**讨厌被当成英华**（本性）。**外壳和本性互成镜像对照**，这就是张力的来源。

**第四步·递增压力：**
- 第一层压力：小学篮球课，母亲强迫他做"英华喜欢的事"
- 第二层压力：同学叫他"克隆人""复印件"
- 第三层压力："比科技更难违背的却是人心"——他意识到问题不在技术，在母亲的执念
- 第四层压力：他必须选择——继续做"英华的影子"，还是成为自己

**第五步·高潮改变人性：** 哭了一晚上，**他决定要成为一个有独立人格的人**。提笔写信。

**收束一句（"说"）：** "妈，科技是为人性服务的，而不能违拗了人性。它成全了你的爱，也请你成全我独立的心……"

**母题定位：** 成长母题（从"英华的影子"到"独立的人"）+ 科技伦理主题

> **教师批注：** 这篇最妙的设计是**"番茄炒蛋"这个具体物件**——它不是随便的道具，它是一个**压力按钮**。母亲看见儿子吃番茄炒蛋就想起"英华 14 年前就爱吃"，儿子吃番茄炒蛋就意识到自己被当成替代品。同一道菜，对母亲是安慰，对儿子是囚笼。**这就是"场景搭建"里"转折点"的用法——小物件承载大冲突。** 让学生学这个动作：**不要泛泛写场景，要找一个具体物件承载你想要的所有矛盾。**
> 
> 另一个值得标记的点：**"我"的选择**——不用 14 年前那个母亲的视角写，也不用 14 年的少年视角一镜到底，而是**先母亲视角→再转到少年视角→最后以少年写信作结**。视角的切换让两个人的困境都被看见了，但情感落点在少年的独立。这是高级的叙事设计，铧阳这种高势能学生应该学。

## 四、场景、事件、四维背景

### 1. 四维故事背景

写好一个故事，首先要确定它发生在什么"时空"里。麦基提出**四维故事背景**：

| 维度 | 定义 | 例子 |
|------|------|------|
| **时代** | 故事在时间中的**位置** | 当今世界、历史时期、假想未来 |
| **期限** | 故事在时间中的**长度** | 几十年、几年、几小时 |
| **地点** | 故事在空间中的**位置** | 城市、乡村、室内、战场 |
| **冲突层面** | 故事在人类斗争**层级体系**中的位置 | 个人内心、人际、社会机构、自然环境 |

**为什么这四维重要？**

因为**同样一件事，在不同四维背景里意义完全不同**。

举例：同样是"单身母亲抚养孩子"——
- 城市中的打工单亲母亲：困境是房租、学费、时间不够
- 偏远山民的单亲母亲：困境是交通、教育资源、文化隔阂
- 抗战时期的单亲母亲：困境是战火、避难、保命

**你的故事是什么类型的困境，取决于你的四维背景怎么设定。**

> **教师批注：** 这一条是给高强度学生讲的（铧阳级）。一般学生能掌握起承转合+两难之选就够了。但如果学生想冲一类上，这一页的"冲突层面"要讲透——很多学生写记叙文停留在"个人内心"这一层（我很难过我很开心），冲突层面上不去，立意就浅。让学生意识到：**把个人困境放到更大的冲突层面（社会、时代、自然）上，立意自动深一层。**

### 2. 事件——价值的变化

麦基的核心洞察：**故事 = 一个价值从一极转到另一极的过程。**

- 事件开头的价值 ≠ 事件结尾的价值
- 这种变化必须是**实质的**（正面转负面，或负面转正面）
- 变化**不可逆转**

**如果故事开头和结尾的价值一样，那就不是故事，是"事件记录"。**

**常见的价值对**：
- 生 ↔ 死
- 爱 ↔ 恨
- 希望 ↔ 绝望
- 自由 ↔ 束缚
- 真诚 ↔ 虚伪
- 勇敢 ↔ 怯懦
- 理解 ↔ 隔阂

写记叙文之前问自己：**我的故事里，开头和结尾的价值是什么？它们是否完成了翻转？**

### 3. 场景搭建的三件套

每一个场景（不是整篇，是每一段）都应该有：

- **转折点**：撕开期望与结果之间的鸿沟，获得惊喜
- **伏笔**：为后面的情节埋下合理化的种子
- **情感转变**：必要而精确的体验

核心原则：**场景必须导致细微而又意义重大的变化——让它成为一个细微、适中或重大的转折点。**

换句话说：**没有不含转折的场景。** 如果一段写完价值没动，那段就该删。

### 4. 《伤心儿女》——事件价值转化与记忆移植的典范

**1999 北京高考满分作文**，题目"假如记忆可以移植"。这篇用**科幻设定 + 家庭伦理**做了当时让所有人震撼的故事：

> **伤心儿女**
> 
> 母亲躺在医院的病床上，双眼紧闭，嘴唇乌紫，她中风的脑子迷迷糊糊的，已经 3 天了。
> 
> 前两天，母亲的床前是没有人的，而今天，她的 3 个子女破天荒地都到齐了。老大一脸横肉，倚着床，盯着母亲，眼里有一种攫取的光。小弟小妹各有心事，又仿佛等待着什么。
> 
> 病房的门被推开，一个声音叫道："3 号床，准备记忆移植。"护士的话音刚落， 3 个人几乎同时一跃而起。
> 
> 他们 3 个人将同时移入母亲的记忆，原因很简单，眼看着母亲快不行了，他们私下开始讨论分遗产的问题。但由于母亲突然中风，什么话也没留下，加上 3 个人以前从未照顾过母亲，对母亲有多少财产谁也不知道底细。
> 
> "记忆移植进入程序。"随着医生的话， 3 个人立即在大脑里开始了搜寻：……一间阴暗的小屋，潮湿，肮脏……沾满油渍的锅台，落灰的橱顶……这不是母亲的家吗？这样陌生，却又熟悉。老大心想，当自己含冤入狱时，是母亲四处奔走，解救了他；又是在这间屋里，他休养了一年，然后自己找了媚子当老婆。媚子逼着他抢占了母亲的堂屋，把母亲赶进了这间破房。从此，自己就再没有踏进这破屋门槛。
> 
> 小妹开始了"回忆"：……腹部的痉挛，巨痛袭来，生下一个血糊糊的孩子。这孩子的双眼被血糊了个严实，睁不开。有人低下头，在孩子眼上一口一口地吮，吮了七七四十九天，血淤散尽后是一双明亮的眼睛……这不是我吗？妈说过我小时候眼睛睁不开，原来是这样。小妹的心一阵抽搐，正是这双眼睛，给了母亲多少白眼。
> 
> 小弟脑海中闪出这样一幅图景：在自己家里，媳妇在大桌上吃得有滋有味，母亲却在门边的一张小凳上，手里拿着一个洋铁碗。媳妇不时用刀子般的眼光剜着母亲……这大约是去年冬天，母亲来自己家住的那些日了。我忙得不着家，原来小蓓是这样对待母亲，难怪有一天回家看见母亲在擦眼睛，我问她，她还说没什么。
> 
> 3 个人都在"记忆"中泪眼模糊。他们都"回忆"到了一个大包裹，土里土气的没见过。他们怀着沉重的心情打开老屋的门，找到那个包裹，令他们大吃一惊的是，包裹是一双双崭新的保暖鞋，大大小小的，红红蓝蓝的。他们用哽咽的声音数着："一双、两双、三双……"

**事件的价值转化拆解：**

**起（召唤）**：中风母亲 + 三个从未照顾过她的子女 + 记忆移植技术。三个子女进入这个情境的动机是**自私的**（分遗产）。

**承（考验）**：三个子女分别在母亲的记忆里看到：
- 老大：看到自己含冤入狱时母亲四处奔走救他——**而他自己娶妻后让媳妇把母亲赶进了破房**
- 小妹：看到母亲七七四十九天用嘴吮她眼睛上的血——**而她长大后给了母亲多少白眼**
- 小弟：看到媳妇虐待母亲——**而他当时没有察觉，母亲什么也没说**

**转（和解）**：价值在每个人身上开始翻转。他们不是"去搜寻遗产"，是"被母亲的爱击中"。

**合（回归）**：打开母亲留下的大包裹——**里面是"一双双崭新的保暖鞋，大大小小的，红红蓝蓝的"**。这是全篇最硬的一击：母亲什么都没留下，只留了这个——**她在等着给子女和孙辈做过冬的鞋**。三个子女用哽咽的声音数着"一双、两双、三双……"

**价值转化的完整链条：**
- 开头：贪婪（三子女）vs 无言（母亲）
- 结尾：忏悔（三子女）vs 被看见的爱（母亲留下的鞋）

**从"自私的遗产争夺"翻转到"迟来的忏悔"——这就是价值的实质翻转，不可逆转。**

**母题定位：成长母题**（从自私到忏悔）+ **对抗母题**（人性的贪婪 vs 亲情的无言）

> **教师批注：** 这篇最狠的设计是**"记忆移植"技术被用来做伦理暴露**——不是科幻的炫技，是借科幻外壳做伦理审判。**这就是"英雄之旅"里"超自然世界不必是魔法"的完美示范**：记忆移植是"超自然"的设定，但故事内核是最日常的——子女对母亲的忽视、母亲无言的爱。
> 
> 另一个教学点：**结尾那个大包裹的"鞋"**——这个物件是全篇的 **"诗眼"**。一切的情感、价值、冲突，最后都落在"一双双崭新的保暖鞋"上。**学生要学的动作：在故事的最后一刻，给你想表达的所有东西找一个具体物件承载。** 不要用"我感动了""我后悔了"这种抽象情绪词收束，用物件收束。
> 
> 对照一下：《赤兔之死》的收束是一句话（玉可碎而不可损其白），《与科技相遇》的收束是一封信，《伤心儿女》的收束是一个物件（鞋）——**这三种收束都比"我感悟到了"高级得多。**

## 五、《此刻，我必须说》实战应用

### 1. 题目与评分标准

**2026 海淀一模作文题：**

> 请以"此刻，我必须说"为题目，写一篇不少于 700 字的记叙文。
> 要求：思想健康；内容充实，合理，有细节描写；语言流畅，书写清晰。
> **（无导语，全命题）**

### 2. 四要素拆解

**切题的唯一标准：四要素俱在，且相互作用。**

| 要素 | 内涵 |
|------|------|
| **此刻** | 特定、具体、正在进行的**瞬间**。极强**现场感**和**紧迫感**。背后承载**长期铺垫、复杂关系、深厚情感**。可以是：矛盾爆发的顶点 / 真相将被掩盖的瞬间 / 情感再也无法压抑的临界点 / 需要做出重大抉择的关口 |
| **我** | 第一人称视角。"说"的**发出者** + 亲历事件 + 做出决定 + **内心挣扎**【设计】。通过"我"的内心活动展现从犹豫、矛盾到最终决定"必须说"的完整心路历程 |
| **必须** | 题眼。**不是"想说、要说、可以说"，意味着不得不说，非说不可，不吐不快**。一种无法抗拒的内在驱动力（源于良知、责任、情感或道义的强烈冲动）。**可能隐含"说"这个行为存在某种阻力**（外部：权威、人情、后果 / 内部：胆怯、顾虑、犹豫）【设计】 |
| **说** | 悬念（语言）。一句**道歉** / 一句**感谢** / 一句**表白** / 一句**反驳** / 一句**真相** / 一句**劝告** / 一句**宣言**…… **承载主题（说什么？怎么说？说的结果？）** |

### 3. 四要素与起承转合的映射

**这是整套讲义的核心图。**

```
起（召唤）   →  铺垫背景，建立"我"的日常状态
承（考验）   →  困境或阻力出现，"我"陷入两难
转（和解）   →  【此刻！】压力到顶点，"我"做出决断（必须！）
合（回归）   →  【说！】说出那句话，价值翻转完成
```

**关键认识：**
- "此刻"不是整篇文章的"开头"，是**转的位置**（爆发点）
- "必须"的驱动力在**承 → 转**之间显形（两难之选的压力）
- "说"在**合**的位置承载主题

**三种常见的考场失败（来自海淀一模阅卷总结）：**

- **多个"此刻"**：叙事结构有两个高潮，破坏了起承转合的单一爆发
- **不是"我"说**：通篇第三人称或由他人说，违反"我"作为说的发出者
- **就是不"说"**：擦边球（留言簿、便利贴、与妻书）或写成"感"（全是感悟、反思，没有一句具体的话）

### 4. 2026 海淀一模标杆文 1 号（一类上，基准 46）

**完整原文：**

> **此刻，我必须说**
> 
> 对于小时候的我来说，回家时沉默不语是一种常态，不仅是因为不爱说，更是因为不能说。我始终学不会那拗口的乡音，带着儿化音的普通话，在满是南方方言与蹩脚普通话的环境里显得格格不入。只要我一开口，同龄的小孩便会立刻投来惊奇的目光，或是直接笑出声来。那笑似乎并无恶意，却深深刺痛着我，无时无刻不提醒着我：自己是个"异类"。我仿佛已不被这南国的山水接纳，即便我流着与这里的人一样的血。我索性闭嘴，不愿徒增麻烦。
> 
> 然而，这份沉默不仅对着陌生人，连至亲之间，也横亘着一层无形的隔阂。外公外婆不会用惊奇的眼光看我，但我一开口，我们总要再三追问我刚刚说了什么。我们吩咐我做事时，半懵半懂的我只能"嗯啊"应着，如此一来，即便最真挚的亲情，也难免被这层隔阂挡在门外。那些浑浊的乡音，在我耳中也愈发聒噪。我于是躲进房间，将门重重一关。
> 
> 可这也无济于事。乡下人最爱串门，每当有人来喊外公外婆，我总难免被牵扯进我们的注意里。那呼唤的声音高亢、迅疾又热烈，正如同我脚下这片红土地的性子。渐渐地，我开始留意到我们对话里某些高频的特殊词汇。我们说人直立，不说"站"，而说"跂"——那是一种苍古的回响，仿佛一位身着右衽衣衫的老者，二十六块椎骨节节挺直时，骨骼间漾出的微响。我们说旁人，不说"我"，而说"渠"。恍惚间，我似看见漫山红杜鹃在风中摇曳，溪水在青石间叮咚作响。
> 
> 回过神时，那乡音已不再嘈杂。我张了张嘴，想模仿那腔调，可嘴里挤出的却是不伦不类的怪声，这让我再度闭紧了嘴。
> 
> 假期转眼便到了尽头。接我去车站的车停在门口，外婆紧紧攥着我的手，絮絮叨叨说了许多。她的语速又快又急，再加上引擎的轰鸣，我只能不住点头。上了车，关上车门，玻璃窗将我与窗外的南国故土隔成了两半。外婆挥着手，忽然用尽全身力气朝我喊：
> 
> "仔啊，好好困告，好好恰饭！"这是方言里"好好睡觉，好好吃饭"的说法。她用熟长的乡音，把最朴素的关心，以她认为我能听懂的方式，递到了我面前。瞬间，心中的屏障轰然倒塌，我按下车窗，泪水在眼眶里打转。
> 
> 顾不得了，此刻，我必须说：
> 
> "阿婆，你喱好好保重哦！"
> 
> 我不知道她是否听得懂我怪异的乡音，但我相信她明白了——因为我看见，她的眼里闪着泪光。
> 
> 列车疾驰，南国的山水次第向后退去。或许从来就没有什么隔膜，不过是我的沉默筑起了一道障壁。那些爱我的人一直都在试着敲开它，用最笨拙的方式，我却始终熟视无睹、听而不闻。
> 
> 但幸好，我终于说出来了。
> 
> 南风掠过耳畔，带着丝丝暖意。

**阅卷点评：** 文中的"我"形象鲜明，有丰富的情感体验和较深的文化思考，"我"的成长与体悟让"此刻"和"必须说"的发生自然合理，"此刻"中的细节呈现让"必须说"背后的自我突破与情感升华真挚动人，感染力强。

---

**四要素 × 起承转合映射：**

**起（召唤）——第 1 段：**
> "对于小时候的我来说，回家时沉默不语是一种常态……我索性闭嘴，不愿徒增麻烦。"

**"我"的日常状态建立：** 因乡音不通被同伴嘲笑，自认异类，主动沉默。
**两难结构初步显形：** 说 → 被嘲笑；不说 → 自我封闭。

**承（考验）——第 2-4 段：**
> "外公外婆不会用惊奇的眼光看我……我于是躲进房间，将门重重一关。"
> "渐渐地，我开始留意到我们对话里某些高频的特殊词汇……"
> "我张了张嘴，想模仿那腔调，可嘴里挤出的却是不伦不类的怪声……"

**压力层层加深：** 
1. 第 2 段：沉默扩散到至亲——亲情被隔阂挡住
2. 第 3 段：开始"留意"乡音（本性露一角：他其实对乡音是有感觉的）——外部面貌（拒绝乡音）与深层本性（对乡音好奇）形成**对照**
3. 第 4 段：尝试模仿失败——挣扎显形，**两难加深**

**转（此刻！）——第 5-6 段：**
> "外婆挥着手，忽然用尽全身力气朝我喊：'仔啊，好好困告，好好恰饭！'……瞬间，心中的屏障轰然倒塌……"

**这是"此刻"——特定、具体、正在进行的瞬间。** 背后承载三段的铺垫（沉默、隔阂、尝试）。
**触发源：外婆用方言喊出最朴素的关心。** 这是外部信号，但它击穿了"我"的内部屏障。
**必须的驱动力爆发：** 如果不说，就永远错过——这是"两恶取其轻"的两难。**不说：更大的恶（辜负外婆最后的关心）。**

**合（说！）——第 7-10 段：**
> "顾不得了，此刻，我必须说：'阿婆，你喱好好保重哦！'"

**这是"说"——一句承载主题的具体话。** 不是感悟，不是总结，是**一句方言问候**。
**用方言回应外婆。** 这是巨大的价值翻转——从"因为乡音沉默"到"因为乡音而说"。

**后面几段是回归后的反思：** "或许从来就没有什么隔膜，不过是我的沉默筑起了一道障壁……但幸好，我终于说出来了。"

---

**两难之选分析：**
- **说的代价**：暴露自己不标准的方言，可能被嘲笑
- **不说的代价**：辜负外婆跨越语言障碍的最后关心，永远错过

**"两恶取其轻"**——暴露的代价小于错过的代价，所以"**必须**说"。

**母题定位：成长母题**（从沉默的局外人到主动融入故土的承传者）

> **教师批注：** 这篇是所有标杆文里两难之选最精致的一篇。关键在于**外婆先用方言喊了那一句**——这不是"我"一个人的独白决断，是**外婆先跨了一步**，然后"我"必须回应。这就是评分标准说的"外界触发 + 内心冲突 → 价值判断 → 最终决断"的完整机制。
> 
> 这篇里"说"的那句话极短：**"阿婆，你喱好好保重哦！"** 只有 10 个字。但它承载了：① 回应外婆的方言关心 ② 认领乡音身份 ③ 打破自我筑的沉默屏障 ④ 完成从"异类"到"传承者"的身份转变。**学生要学的：说的那句话不需要长，需要承载多层意义。**

## 六、学生作品范例：两篇高一类文

### 1. 《因为热爱，所以奔赴》——2023 丰台二模

**题目：** 请以"因为热爱，所以奔赴"为题目，写一篇记叙文。

> **原文：**
> 
> "号外号外，巴黎谈判失败！"小小的身躯穿梭在巷子里，雨滴落在地上，发出滴答滴答地声音。
> 
> "给我拿份报纸"报童抬起头，面前的青年穿着米白色的衬衫，虽是麻布料子，但也能看出来是精心洗过的。"一角八分钱"青年麻利地付过钱，小跑着，跑出了巷子。
> 
> 在一栋老房子前，青年停住了脚步，他跺了跺脚，甩了甩被淋湿的头发，摆出一个最阳光的笑容，伸出手推开了门。"阿飞，回来啦"女人停下了手中的动作"新给你做得衣服，快去穿上试试"女人说着，将手中的衣服递了出去。阿飞却没有接，低着头，欲言又止。女人见儿子支支吾吾的样子，便知道他要说些什么了，"下午是不是又要去游街，我早跟你说过了，在这个时代，明哲保身才是最重要的！你为什么非要去当这个出头鸟呢！"他没有出声，道了歉后，又推开了门。
> 
> 雨越下越大，原本热闹的街巷猛地寂静下来，只听得到雨滴落在地上的滴答声。蓦地，有响声自远方传来，一群约摸十八九岁地青年声势浩大地向前走来"废除二十一条！还我青岛！"一面面旗帜在空中飞舞起来，宣誓着他们的决心。警察整齐的伫立在远方，手中的枪支威胁着他们的前进。栏杆被拉起，却仍然没有阻挡住他们前进的步伐。粗糙的木头挡在青年身前，洁白的衣服被鲜血染红，转瞬之间又被雨水冲刷，只剩下一道道的划痕。"砰！"一声声巨响打断了行走的步伐，阿飞眼前闪过一片空白，逐渐失去意识。
> 
> 又过几年，青年的脸上早已褪去青涩，胸口的伤疤似蜈蚣一样攀附在他的身上，但并不让人觉得恐怖。每当有人问起他参军的缘由，他总会骄傲的笑着说："我不求什么功勋名利，不求青史留名，只是想保护这个我从小生活的地方，如果总有人要去冲锋陷阵，那为什么不能是我呢？"
> 
> 但在无人的角落里，阿飞却总能回忆起他离开家时的情形，"妈知道劝不动你，出门在外，记得保护好自己。"母亲麻利的为他收拾着行李，眼角的泪水却出卖了她此刻的心情。阿飞离开了家，女人知道，他大概不会再回来了。他要去奔赴，他热爱的事业了。

**四要素 × 起承转合拆解：**

**起（召唤）**：报童在雨中叫卖"巴黎谈判失败"的消息 → 青年阿飞买报纸 → 回家。这是五四运动的历史背景被**场景化**植入。

**承（考验）**：母子冲突。母亲做了新衣服让阿飞穿上——但她知道儿子要去游街。**"下午是不是又要去游街，我早跟你说过了，在这个时代，明哲保身才是最重要的！"** 母亲的爱 vs 阿飞的信念，**两难之选：尽孝保身 vs 为国奔赴**。

**转（此刻！）**：游街现场。警察的枪威胁、栏杆被拉起、洁白衣服被鲜血染红、"砰！"的一声——这是**集体的、物理的、极端的"此刻"**。阿飞在这一刻失去意识，也在这一刻做出了他的选择：**不是退缩，是加入**。

**合（回归/说！）**：参军后的阿飞回忆起那一天。"说"在这里分成两层：
- 对外界的"说"：**"我不求什么功勋名利，不求青史留名，只是想保护这个我从小生活的地方，如果总有人要去冲锋陷阵，那为什么不能是我呢？"**
- 对母亲的"说"（母亲说给阿飞）：**"妈知道劝不动你，出门在外，记得保护好自己。"**

**两层"说"的精妙**：阿飞对外说的是信念宣言，母亲对阿飞说的是不舍的叮咛。**两者同时存在，构成完整的人物弧光——阿飞既选择了信念，也承担了离别的代价。**

**价值转化**：从"害怕让母亲伤心但又必须去"（两难）→ "选择了信念，但也带着母亲的祝福走"（两难的和解）。不是简单的"告别家庭投身革命"，是**把家庭的爱作为信念的一部分带走了**。

**母题定位：成长母题 + 对抗母题**（对抗"明哲保身"的时代潮流）

> **教师批注：** 这篇是学生作品。Emrys 当时的编辑动作是：改结构、找冲突、强化人物。小孩本来有素材（五四青年阿飞）也有情感（母子不舍），但结构散、冲突不聚焦、人物面貌模糊。
> 
> **学生做对的事：**
> 1. 用"雨"贯穿全篇——开头雨中叫卖、中间雨中游街、雨水冲刷血迹。雨不是装饰，是**情感密度的载体**
> 2. 用"衣服"做物件——母亲做的新衣服（起），游街时被血染红的洁白衣服（转），收拾行李时母亲麻利的动作（合）。同一个"衣"的意象在三个阶段承载不同的情感
> 3. 不拔高——阿飞最后说"不求功勋名利"，不喊口号。学生没落入"伟光正"的陷阱
> 
> **这篇的教学价值：** 让学生看见"对抗母题 + 成长母题"怎么叠加——阿飞对抗的不是警察、不是军阀，是**母亲的爱**和**明哲保身的时代逻辑**。**真正的对抗永远是内部的、艰难的、有代价的。**

### 2. 《又见灯塔》——2021 东城高三上期末

**题目：** 材料中"灯塔"象征希望、智慧，比喻人生的理想和目标。请以"又见灯塔"为题目，写一篇不少于 800 字的记叙文。

> **原文：**
> 
> 此刻我站在墓前，披白戴孝，墓中躺着的是诸葛丞相，我心中唯一的灯塔。
> 
> 我曾跟随丞相六出祁山，夜深人静之际，我站在山峦之上，俯瞰大营，总有一个帐中亮着荧荧灯火，那便是丞相的中军帐。帐中的丞相，常常望着先主的画像，喃喃自语："此生报心，可付丹鼎。数不尽日夜春秋，昭炎汉室长明……"只要有丞相在，大汉必将复兴！
> 
> 只可惜，丞相积劳成疾，最终病逝五丈原。蜀汉的灯塔从此黯然无光。
> 
> 丞相的葬礼之后，我等老兵也归入姜维将军麾下。彼时朝廷分为主战派与主和派，将军力主北伐，屡次上表请战，皆石沉大海。无奈之下，将军回都，入朝面圣，亲自请战。
> 
> 三跪九叩、一番寒暄。朝堂之上，便再没有了声音。主和之臣早已正襟危立，对他们而言，这里才是真正的战场，他们想要以唇为枪、以舌为剑，在天子面前，说服姜将军。蒋琬率先打破沉默，道："丞相六出祁山，为蜀汉搏得一线生机，有了跟曹魏谈和的资本。此时出兵，将错失谈和之机。长年征战，民生疲敝，辎重粮草已不盈年。且丞相新去，兵将早已无心再战，兵出必败。"
> 
> "司徒所言极是，然与曹魏谈和终非长久之计。今曹魏已受重创，元气大伤，且司马与曹家二心，实乃破敌良机。若士气不佳，吾等可效仿先帝，隐瞒丞相死因，引祸水于曹魏，兵将必愤慨曹魏之暴行，戮力同心，讨伐汉贼。"谏言，却遭贬谪，到了刘谌手下做官。
> 
> 刘谌啊，进谏次数不比我少，可大多都石沉大海，杳无音信。他也常常用轻松的语气与我们讨论国家大事，事事燃急，却被他一一化解。
> 
> 后来，听闻邓艾要降，刘谌便带吾等进朝劝谏。在威严肃穆的大堂之中，除去臣子们的讲话声，剩下的便是肃静。本该是这样的，却不知何时多出了几架钟罄，琴色和鸣。到了刘谌谏言，他说的那些话具体老臣已经淡忘，但却字字珠玑，关乎民生大计，关乎蜀汉未来……只可惜后主庸懦，未被采纳，只记得刘谌那炯炯有神的眼睛，终是燃上了绝望。见劝谏无果，刘谌愤而拔剑，一语响破寰宇，道："臣等随陛下多年，为我大汉尽心尽力，今预见国破之景，臣不愿。故臣宁可身死失社稷，绝不拱手让江山！"说罢，举剑自刎于朝堂。只是可惜，他的死除了让御前侍卫无措，台下百官议论纷纷外，便再没了作用。
> 
> 第二天，朝堂之上又添置了几顶钟罄，又是一番琴色和鸣。
> 
> 见劝谏无望，我便回到了原本刘谌所驻守的地方。百姓叹息他的死，可声音传不到上面，我取出了他生前所穿的衣服，为他在故地立了衣冠冢。
> 
> 在墓前，我突然发觉他好像和一位故人那么像，好像是另一位已经黯淡了的灯塔。

**四要素 × 起承转合拆解：**

**起（召唤）**：开篇直接进入墓前场景——"此刻我站在墓前，披白戴孝"。回忆诸葛丞相的灯塔形象。这是巧妙的**时序倒置**——用结尾场景做开篇，营造"我已经失去了一切"的基调。

**承（考验）**：诸葛亮病逝五丈原 → 姜维主战 vs 主和派 → 蒋琬主和论 → "我"主战论遭贬谪到刘谌手下。**这一段是政治困境的层层加深**——主战派被边缘化，但"我"仍然相信。

**转（此刻！）**：刘谌朝堂劝谏。钟罄和鸣、刘谌字字珠玑、后主庸懦不纳。**爆发点：刘谌拔剑自刎**。

**"说"在这里：** **"臣等随陛下多年，为我大汉尽心尽力，今预见国破之景，臣不愿。故臣宁可身死失社稷，绝不拱手让江山！"**

**合（回归）**：刘谌死后的余震——"他的死除了让御前侍卫无措，台下百官议论纷纷外，便再没了作用。"第二天朝堂依然"钟罄和鸣"。**这是冷酷的现实回应。** "我"回到刘谌驻守的地方，用他的衣服立衣冠冢。

**收束一句：** **"在墓前，我突然发觉他好像和一位故人那么像，好像是另一位已经黯淡了的灯塔。"**

这一句**完成了"又见灯塔"的题意落点**——诸葛亮是第一座灯塔（第 1 段），刘谌是第二座灯塔（结尾）。"又见"不是简单的重见，是**在灯塔熄灭后又见到新的灯塔**——虽然新的灯塔也已经黯淡。

**母题定位：对抗母题 + 人物原型母题**（对抗历史的黑暗潮流 + 诸葛亮/刘谌作为忠义原型）

**"我"的叙事角色：** 老兵——**见证者**。这是极高级的叙事设计。为什么不用诸葛亮或刘谌做"我"？因为：
- 诸葛亮做"我"，就是**当事人**，失去了"见证"的叙事距离
- 刘谌做"我"，自杀之后故事就断了
- 老兵做"我"，可以**跨越两代灯塔**的陨落，用"活着的人"的视角见证"死去的理想"

**这是档案里讲过的"为什么只能由我来说"的最高级回答——因为只有老兵能看见两代灯塔的连续陨落，只有他能"又见"。**

> **教师批注：** 这也是学生作品，是对这套方法论的最完整示范。学生做对了这几件事：
> 
> 1. **时序倒置开篇**——用"墓前"场景做起，营造悬疑感。这是成熟的叙事技巧
> 2. **两代灯塔的结构**——"又见灯塔"的"又"字被学生以叙事结构实现，不是靠抒情表达
> 3. **"我"作为见证者**——叙事角色设计精准，不是当事人
> 4. **对历史细节的调用**——蒋琬的主和论、刘谌的朝堂自刎，都是真实史料。学生不是生造，是借用
> 5. **冷酷的"合"段**——"第二天朝堂之上又添置了几顶钟罄，又是一番琴色和鸣。"不用煽情，用"朝堂依旧"的冷酷现实反衬刘谌的死毫无意义。但毫无意义本身，才让"我"立衣冠冢的动作有了重量
> 6. **文言叙事的功力**——学生不是炫技，是用文言节奏配合历史时代感
> 
> 这篇最精妙的是**两处"灯塔"的对照**：
> - 诸葛亮的灯塔 = "荧荧灯火" + "此生报心，可付丹鼎" —— **亮着的时候**
> - 刘谌的灯塔 = "炯炯有神的眼睛" + "臣宁可身死失社稷" —— **熄灭的时候**
> 
> 两座灯塔都是真的，但一座是活着的亮，一座是死去的亮。学生用叙事把"灯塔"这个题目的所有含义都吃透了。

## 七、考场实战——三问检查清单

写完初稿之后，或者打算动笔之前，用这三个问题自检：

### 第一问：你的两难是什么？

- "说"的代价是什么？
- "不说"的代价是什么？
- 两个代价都不够重 → 不切题（没有"必须"）
- 两个代价清晰 → 继续

**具体模板：**
```
说 → 会失去 _________（代价 A）
不说 → 会失去 _________（代价 B）
A 和 B 都不能兼得 → 这就是你的两难
```

### 第二问：你的爆发点（此刻）在哪里？

- 它是一个**特定瞬间**（不是一段时间 / 不是一种感受）吗？
- 它有**现场感**（声音、动作、物件、温度）吗？
- 它背后承载了**前面铺垫的所有压力**吗？
- 铺垫充分 + 此刻具体 → 合格
- 没有铺垫 / 此刻模糊 → 不合格

### 第三问：结尾有没有一句具体的话？

- 一句**道歉** / 感谢 / 表白 / 反驳 / 真相 / 劝告 / 宣言
- **不是**"我终于明白了……" 这种感悟
- **不是**"从此我……" 这种总结
- **是**主角在那一刻真正说出口的**一句**话
- 有具体的话 → 合格
- 只有感悟 → 不合格

---

### 三问都答上，把骨架填成故事——

```
起：建立"我"的日常状态（外壳）+ 引入压力来源
承：压力加深，两难显形，"我"陷入挣扎
转：【此刻！】一个具体物件 / 动作 / 话语击穿内心屏障 → "我"做出决断
合：【说！】一句承载主题的话 + 价值翻转后的新状态
```

### 字数分配（按 800 字计）：

- 起：150-200 字
- 承：200-300 字（压力是厚度，不能太薄）
- 转：200-250 字（爆发点可以慢，要让读者看见变化）
- 合：150-200 字

**转和合合起来接近一半——因为这两段才是故事真正的重量所在。**

## 附：讲义使用说明

### 给学生的话

这份讲义读完至少一遍。读的时候注意：

1. 每篇范文读两遍——第一遍看故事，第二遍看结构
2. 把《此刻，我必须说》1 号文、《因为热爱，所以奔赴》、《又见灯塔》三篇**抄一遍**——抄的过程会让你感受到"起承转合"的节奏
3. 写作文之前过一遍"三问检查清单"
4. 写完之后再过一遍"三问检查清单"

### 给老师的批注使用

所有灰色引用框的批注是教学重点提示。课堂讲解时可按需展开：

- **红线标记**的问题（蛋膜句、空壳论据、"感"代替"说"）要在学生作品上直接指出
- **绿线标记**的动作（两难识别、物件承载、视角选择）要让学生亲手练
- **黄线标记**的进阶内容（四维背景、视角设计、文化资源调用）只给中上学生
