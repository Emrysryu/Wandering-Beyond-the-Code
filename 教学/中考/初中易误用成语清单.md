# 初中阶段易误用成语清单

整理时间：2026-04-24 20:20 CST

说明：这份清单按初中语文考试常见误用方式整理，重点不是背词典释义，而是抓“对象、语境、褒贬、程度”这些最容易设错的点。

## 第一部分：适用对象很窄，换对象就错

1. **鳞次栉比**：多形容建筑物、船只等像鱼鳞和梳齿一样密集排列，不能随便形容人、书、商品。
   - 易错：人群鳞次栉比。
   - 可用：高楼鳞次栉比。

2. **琳琅满目**：多形容美好的物品很多，陈列在眼前，不能形容事件、风景、想法。
   - 易错：新闻事件琳琅满目。
   - 可用：展柜里的工艺品琳琅满目。

3. **美轮美奂**：多形容建筑物、装饰、布置高大华美，不能泛泛形容自然风景、文章、表演。
   - 易错：黄山云海美轮美奂。
   - 可用：新建的礼堂美轮美奂。

4. **栩栩如生**：形容艺术形象逼真，如绘画、雕塑、文学描写中的形象，不能形容真人本身。
   - 易错：台上的演员栩栩如生。
   - 可用：画中的人物栩栩如生。

5. **络绎不绝**：多形容人、车、船等前后相接，连续不断，不能形容声音、消息、事件本身。
   - 易错：掌声络绎不绝。
   - 可用：游客络绎不绝。

6. **汗牛充栋**：只能形容书籍、文献极多，不能形容商品、作业、资料之外的一般物品。
   - 易错：商场里的衣服汗牛充栋。
   - 可用：古籍资料汗牛充栋。

7. **巧夺天工**：形容人工技艺精巧，胜过自然，不能形容天然景物。
   - 易错：桂林山水巧夺天工。
   - 可用：这件玉雕巧夺天工。

8. **耳濡目染**：形容人长期听到看到而受到潜移默化的影响，不能用于物、事件，也不能只表示“看见听见”。
   - 易错：这座城市耳濡目染了传统文化。
   - 可用：他从小耳濡目染，喜爱书法。

9. **莘莘学子**：指众多学生，“莘莘”本身就是众多，不能说“一个莘莘学子”。
   - 易错：他是一名莘莘学子。
   - 可用：莘莘学子走进考场。

10. **芸芸众生**：指众多普通人，不能指少数人，也不宜用于庄重褒扬个体。
    - 易错：这位英雄是芸芸众生中的楷模。
    - 可用：芸芸众生各有自己的奔忙。

11. **济济一堂**：形容许多有才能的人聚集在一起，不能只表示人多。
    - 易错：菜市场里顾客济济一堂。
    - 可用：专家学者济济一堂。

12. **座无虚席**：形容观众、听众、宾客很多，座位都坐满，不能形容街道、广场、景点。
    - 易错：公园里座无虚席。
    - 可用：报告厅里座无虚席。

13. **门可罗雀**：形容门庭冷落，宾客稀少，常用于场所、机构、门店，不能形容道路宽阔或环境安静。
    - 易错：这条小路门可罗雀。
    - 可用：昔日热闹的店铺如今门可罗雀。

14. **车水马龙**：形容车马或车辆很多，来往不断，多用于街道、交通场景，不能形容思想、文章、声音。
    - 易错：会场里发言车水马龙。
    - 可用：节日前的商业街车水马龙。

15. **川流不息**：多形容行人、车辆、水流等连续不断，不能随便形容抽象事件或声音。
    - 易错：好消息川流不息。
    - 可用：车辆川流不息。

16. **摩肩接踵**：形容人很多，很拥挤，不能形容车辆、书籍、建筑。
    - 易错：汽车摩肩接踵。
    - 可用：庙会上游人摩肩接踵。

17. **人声鼎沸**：形容人群声音嘈杂热闹，不能形容掌声、机器声、自然声。
    - 易错：雷声人声鼎沸。
    - 可用：操场上人声鼎沸。

18. **震耳欲聋**：形容声音很大，快把耳朵震聋，不能形容气势、画面、场面本身。
    - 易错：这幅画震耳欲聋。
    - 可用：震耳欲聋的炮声。

19. **娓娓动听**：形容说话、讲述、朗读委婉生动，使人爱听，不能形容文章内容、景色、音乐之外的纯画面。
    - 易错：这篇风景描写娓娓动听。
    - 可用：老师讲故事娓娓动听。

20. **绘声绘色**：形容叙述、描写生动逼真，不能形容实物本身漂亮。
    - 易错：这件衣服绘声绘色。
    - 可用：他把比赛经过讲得绘声绘色。

21. **惟妙惟肖**：形容描写或模仿非常逼真，不能形容真人自然长相。
    - 易错：这个孩子长得惟妙惟肖。
    - 可用：他的模仿惟妙惟肖。

22. **跃然纸上**：形容文学作品、绘画中的形象生动地呈现在纸面上，不能形容真人或真实景物直接出现。
    - 易错：运动员跃然纸上地冲过终点。
    - 可用：英雄形象跃然纸上。

23. **入木三分**：本义形容书法笔力深，后多形容见解、议论深刻，不能形容表演逼真或声音响亮。
    - 易错：演员把角色演得入木三分。
    - 可用：这段批评入木三分。

24. **力透纸背**：可形容书法遒劲，也可形容文章深刻有力，不能形容声音、动作、态度。
    - 易错：他的歌声力透纸背。
    - 可用：这篇文章力透纸背。

25. **浩如烟海**：形容文献、资料、书籍极多，不能形容人多、商品多、风景多。
    - 易错：游客浩如烟海。
    - 可用：相关史料浩如烟海。

26. **卷帙浩繁**：形容书籍、篇章很多，不能形容任务、商品、人物。
    - 易错：超市商品卷帙浩繁。
    - 可用：这套丛书卷帙浩繁。

27. **俯拾皆是**：形容某类事物很多，到处都是，常用于例子、材料、现象，不能形容珍贵稀有之物。
    - 易错：稀世珍宝俯拾皆是。
    - 可用：这样的例子俯拾皆是。

28. **不绝如缕**：多形容声音细微悠长，也形容局势危急、联系微弱，不能当作“连续不断”的普通替代词。
    - 易错：游客不绝如缕。
    - 可用：远处传来不绝如缕的笛声。

29. **萍水相逢**：指素不相识的人偶然相遇，不能用于老朋友、亲人、长期同学。
    - 易错：我和同桌萍水相逢三年。
    - 可用：两人在旅途中萍水相逢。

30. **青梅竹马**：形容男女儿童时期亲密相伴，不能泛指普通朋友、同学、兄弟姐妹。
    - 易错：我和哥哥青梅竹马。
    - 可用：他们二人青梅竹马。

31. **破镜重圆**：比喻夫妻失散或决裂后重新团圆，不能泛指朋友和好、机构合并。
    - 易错：两位同学破镜重圆。
    - 可用：分别多年的夫妻终于破镜重圆。

32. **相敬如宾**：形容夫妻互相尊敬，像对待宾客一样，不能用于朋友、师生、同事。
    - 易错：我和老师相敬如宾。
    - 可用：这对夫妻相敬如宾。

33. **举案齐眉**：形容夫妻相互尊敬，不能用于普通家庭成员或朋友。
    - 易错：父子之间举案齐眉。
    - 可用：夫妻举案齐眉。

34. **豆蔻年华**：旧指女子十三四岁的年纪，不能用于男生，也不能泛指青年。
    - 易错：这位男孩正值豆蔻年华。
    - 可用：豆蔻年华的少女。

35. **弱冠之年**：古代男子二十岁左右，不能用于女子，也不能用于儿童或老人。
    - 易错：她正值弱冠之年。
    - 可用：他弱冠之年便立下志向。

36. **而立之年**：指三十岁左右，不能泛指“已经独立”。
    - 易错：这个小学生已经到了而立之年。
    - 可用：他到了而立之年，更懂责任。

37. **耄耋之年**：指八九十岁的高龄，不能泛指中年或普通老人。
    - 易错：五十岁的他已到耄耋之年。
    - 可用：老人虽至耄耋之年，仍精神矍铄。

38. **首当其冲**：比喻最先受到攻击、压力或灾难，不能理解为“首先、带头”。
    - 易错：他在活动中首当其冲地报名。
    - 可用：沿海地区在台风中首当其冲。

39. **身临其境**：指亲自到了那个境地，或通过作品获得如同亲临的感受，不能用于纯粹亲眼看见一个普通东西。
    - 易错：我身临其境地看见了黑板。
    - 可用：读到这里，我仿佛身临其境。

40. **设身处地**：指替别人着想，站在别人的处境考虑问题，不能等同于“身临其境”。
    - 易错：我设身处地地来到博物馆。
    - 可用：我们要设身处地为他人着想。

## 第二部分：感情色彩或语用方向反直觉

1. **无独有偶**：多用于不好的事情相继出现，含贬义或中性偏贬，不宜用于好事成双。
   - 易错：他获奖了，无独有偶，同桌也获奖了。
   - 可用：此地发生造假事件，无独有偶，另一地也查出类似问题。

2. **趋之若鹜**：像鸭子一样成群跑过去，多含贬义，形容许多人追逐不正当或不值得追逐的东西。
   - 易错：同学们对经典名著趋之若鹜。
   - 可用：一些人对虚假流量趋之若鹜。

3. **始作俑者**：比喻坏风气、坏事的带头人，贬义，不能用于首创好事。
   - 易错：他是公益活动的始作俑者。
   - 可用：这种不良风气的始作俑者必须被追责。

4. **处心积虑**：长期谋划，多含贬义，不能用于认真筹备好事。
   - 易错：老师处心积虑地帮助学生。
   - 可用：骗子处心积虑设下圈套。

5. **殚精竭虑**：用尽精力思考谋划，褒义或中性偏褒，可用于辛苦工作，不能和“坏事”随便搭配。
   - 易错：犯罪分子殚精竭虑地逃避追捕。
   - 可用：科研人员为攻克难题殚精竭虑。

6. **呕心沥血**：形容费尽心血，多用于褒义，不能形容坏人作恶。
   - 易错：他为诈骗方案呕心沥血。
   - 可用：老师为课程设计呕心沥血。

7. **煞费苦心**：费尽心思，褒贬皆可；考试中如果和“殚精竭虑”“呕心沥血”同时出现，要注意语体轻重和语境庄重程度。
   - 易错：烈士们煞费苦心，为国捐躯。（语体偏轻，配不上“烈士”“捐躯”的庄重程度）
   - 可用：老师为设计这节课煞费苦心。

8. **苦心孤诣**：费尽心思钻研或经营，达到别人达不到的境地，褒义，不能用于阴谋。
   - 易错：他苦心孤诣地设计骗局。
   - 可用：艺术家在构图上苦心孤诣。

9. **绞尽脑汁**：费尽心思，中性偏口语，可褒可贬，但语体较轻，不宜用于特别庄重、沉痛的语境。
   - 易错：先烈们绞尽脑汁，为国捐躯。（语体太轻，配不上“先烈”“捐躯”的庄重程度）
   - 可用：他绞尽脑汁也想不出答案。

10. **粉墨登场**：本指化妆上台演戏，后多比喻坏人经过打扮登上政治舞台或公开场合，常含贬义。
    - 易错：优秀青年粉墨登场，展示才华。
    - 可用：一些投机者粉墨登场。

11. **弹冠相庆**：比喻一人做官或得势，同伙互相庆贺将有官可做，贬义。
    - 易错：运动员夺冠后，大家弹冠相庆。
    - 可用：小集团得势后弹冠相庆。

12. **额手称庆**：把手放在额上表示庆幸，褒义或中性，表示因事情成功或脱险而高兴。
    - 易错：犯罪团伙逃脱后额手称庆。
    - 可用：险情解除后，众人额手称庆。

13. **罄竹难书**：形容罪行很多，写也写不完，贬义，不能形容功劳、成绩多。
    - 易错：他的贡献罄竹难书。
    - 可用：敌人的罪行罄竹难书。

14. **擢发难数**：形容罪恶多得数不清，贬义，不能形容优点多。
    - 易错：他的优点擢发难数。
    - 可用：侵略者罪行擢发难数。

15. **不刊之论**：指不能改动或不可磨灭的正确言论，褒义，不是“不能刊登的言论”。
    - 易错：这篇文章违规，是不刊之论。
    - 可用：这段见解堪称不刊之论。

16. **不易之论**：指不可更改的正确言论，褒义，不是“不容易的议论”。
    - 易错：这道题太难，是不易之论。
    - 可用：他的判断是不易之论。

17. **万人空巷**：形容家家户户的人都从巷子里出来，多指庆祝、欢迎等盛况，不是街巷空无一人。
    - 易错：疫情期间万人空巷，街上没人。
    - 可用：盛大巡游引来万人空巷。

18. **明日黄花**：比喻过时的事物或消息，不是明天的花。
    - 易错：这项新技术是明日黄花，前途广阔。
    - 可用：曾经的热点如今已成明日黄花。

19. **差强人意**：大体上还能使人满意，不是“很差、令人不满意”。
    - 易错：这次考试成绩差强人意，老师非常失望。
    - 可用：方案虽有不足，但差强人意。

20. **不足为训**：不能当作典范或法则，不是“不值得教训”。
    - 易错：他的错误不足为训，不必批评。
    - 可用：这种侥幸成功不足为训。

21. **文不加点**：文章一气写成，无须修改，形容文思敏捷，不是“文章没有标点”。
    - 易错：这篇作文文不加点，读起来很费劲。
    - 可用：他才思敏捷，作文文不加点。

22. **屡试不爽**：多次试验都没有差错，不是“多次试验都不舒服、不成功”。
    - 易错：这个办法屡试不爽，还是失败了。
    - 可用：这个方法屡试不爽。

23. **首鼠两端**：迟疑不决、摇摆不定，贬义，不是“首尾兼顾”。
    - 易错：他处理事情首鼠两端，考虑周全。
    - 可用：关键时刻首鼠两端，必然误事。

24. **左右逢源**：做事得心应手、处处顺利；也可指为人圆滑，两头讨好。考试中要看语境褒贬。
    - 易错：把它一律当褒义或一律当贬义。
    - 可用：他在复杂关系中左右逢源。

25. **八面玲珑**：原可形容人处事圆滑周到，现代多含贬义，指过于圆滑世故；不宜用于真诚赞美。
    - 易错：这位正直干部八面玲珑。
    - 可用：他八面玲珑，谁也不得罪。

26. **老谋深算**：形容人办事老练而有心计，多含贬义，不能随便夸长者有智慧。
    - 易错：这位慈祥老人老谋深算。
    - 可用：这个对手老谋深算，不可轻视。

27. **胸无城府**：形容待人坦率真诚，不会耍心机，是褒义或中性偏褒，不是“没有学问、没有能力”。
    - 易错：他学习差，胸无城府。
    - 可用：他胸无城府，待人坦诚。

28. **危言危行**：说正直的话，做正直的事，是褒义；不是“危险的言行”。
    - 易错：他在网络上危言危行，造成恶劣影响。
    - 可用：君子危言危行。

29. **细大不捐**：小的大的都不抛弃，形容包罗一切，不是“不捐钱”。
    - 易错：他很吝啬，细大不捐。
    - 可用：编写资料时细大不捐。

30. **惨淡经营**：费尽心力经营、筹划，常用于事业艰难创立，不是“经营状况惨淡”。
    - 易错：这家店生意惨淡经营，快倒闭了。
    - 可用：他惨淡经营多年，终于办成学校。

31. **大方之家**：指见识广博或精通某种学问的人，不是“出手大方的人家”。
    - 易错：他花钱豪爽，真是大方之家。
    - 可用：这番见解恐怕要贻笑大方之家。

32. **空谷足音**：比喻难得的音信、言论或事物，常含珍贵意味，不是山谷里的脚步声。
    - 易错：旅游时听见空谷足音。
    - 可用：他的提醒如空谷足音。

33. **目无全牛**：形容技艺达到极其纯熟的境界，褒义，不是“眼里没有整体观念”。
    - 易错：他做事目无全牛，只看局部。
    - 可用：庖丁解牛，目无全牛。

34. **七月流火**：指农历七月天气转凉，不是七月天气炎热如火。
    - 易错：七月流火，骄阳似火。
    - 可用：七月流火，暑气渐退。

35. **炙手可热**：比喻权势大、气焰盛，使人不敢接近，多含贬义，不是“很受欢迎、很热门”。
    - 易错：这位明星炙手可热，深受喜爱。
    - 可用：权臣炙手可热，众人避让。

36. **脍炙人口**：比喻好的诗文或事物被人传诵称赞，褒义，不能和“炙手可热”混用。
   - 易错：这首诗炙手可热。
   - 可用：这首诗脍炙人口。

37. **侧目而视**：斜着眼睛看，形容畏惧又愤恨，贬义或负面语境，不是“特别关注”。
   - 易错：大家对他的成功侧目而视。
   - 可用：暴行令人侧目而视。

38. **望其项背**：多用于否定式“难以望其项背”，表示赶不上。不能误用为“能够比较”。
   - 易错：他的水平可以望其项背。
   - 可用：后辈很难望其项背。

39. **不忍卒读**：不忍心读完，常因文章内容悲惨动人；不是文章写得差，读不下去。
   - 易错：这篇作文错字太多，令人不忍卒读。
   - 可用：灾难记录令人不忍卒读。

40. **不堪卒读**：文章差得读不下去，贬义，容易和“不忍卒读”混淆。
   - 易错：烈士家书不堪卒读。
   - 可用：这篇病句连篇的文章不堪卒读。

## 快速判别口令

1. 看对象：这个成语到底修饰人、建筑、书籍、声音、艺术形象，还是夫妻关系？
2. 看褒贬：是不是把贬义词拿去夸人，或把褒义词拿去写坏事？
3. 看程度：是不是“大词小用”，把很严重、很极端的词用在普通小事上？
4. 看字面陷阱：差强人意、不刊之论、万人空巷、文不加点这类，不能按字面猜。
5. 看固定搭配：有些词几乎有固定使用场景，换对象就容易错。

## 第三部分：别的方法——按误用机制抓

### 一、望文生义：字面看着很熟，其实意思反着来

1. **不以为然**：不认为是对的，表示不同意；不是“不放在心上”。
   - 易错：他对考试不以为然，结果没复习。
   - 可用：大家都赞同，只有他不以为然。

2. **不以为意**：不放在心上，不重视。
   - 易混：和“不以为然”混用。
   - 可用：他对别人的提醒不以为意。

3. **不孚众望**：不能使大家信服，辜负众人期望；不是“不负众望”。
   - 易错：他夺冠了，真是不孚众望。
   - 可用：这次处理结果不孚众望。

4. **不负众望**：没有辜负大家期望。
   - 易混：和“不孚众望”只差一个字，意思相反。
   - 可用：他不负众望，取得冠军。

5. **空穴来风**：原多指消息和传说不是完全没有原因；现在也常被误用为“毫无根据”。考试中要看语境，慎用。
   - 易错：这完全是空穴来风，没有任何根据。
   - 稳妥：改成“无稽之谈”“毫无根据”。

6. **三人成虎**：比喻谣言重复多次，就能使人信以为真；不是三个人真的打虎。
   - 易错：三人成虎，终于制服了猛兽。
   - 可用：谣言三人成虎，必须及时澄清。

7. **登堂入室**：比喻学问或技艺由浅入深，达到较高境界；不是进入房屋。
   - 易错：小偷登堂入室。
   - 可用：他的书法已登堂入室。

8. **登峰造极**：比喻学问、技艺等达到最高境界；也可用于坏事发展到极点，褒贬看语境。
   - 易错：把它固定当褒义。
   - 可用：技艺登峰造极；恶行登峰造极。

9. **如坐春风**：像坐在春风中，比喻受到良师教诲，不能形容天气舒服。
   - 易错：今天阳光好，我如坐春风。
   - 可用：听先生讲课，如坐春风。

10. **春风化雨**：适宜草木生长的风雨，比喻良好教育的熏陶，不能只写自然天气。
    - 易错：春风化雨，庄稼长势很好。
    - 可用：老师春风化雨般的教导影响了他。

11. **瓜田李下**：比喻容易引起嫌疑的地方或处境。
    - 易错：瓜田李下，果实累累。
    - 可用：为避瓜田李下，他主动回避。

12. **火中取栗**：比喻替别人冒险出力，自己却上当吃亏。
    - 易错：他火中取栗，终于获得成功。
    - 可用：不要替人火中取栗。

13. **洛阳纸贵**：形容著作流传很广，风行一时，不能形容纸价上涨。
    - 易错：最近纸价上涨，洛阳纸贵。
    - 可用：新书一出，洛阳纸贵。

14. **曾几何时**：时间过去没有多久，不能理解为“曾经、很久以前”。
    - 易错：曾几何时，古人就发明了造纸术。
    - 可用：曾几何时，这里还是一片荒地。

15. **久假不归**：长期借用不归还，不是“长期请假不回来”。
    - 易错：他病假久假不归。
    - 可用：公物久假不归，应当追回。

### 二、语义重复：成语本身已经含有某个意思，前后又说一遍

1. **忍俊不禁**：忍不住笑，不能说“忍俊不禁地笑了”。
   - 改法：忍俊不禁；或忍不住笑了。

2. **贻笑大方**：让内行人笑话，不能说“被人贻笑大方”。
   - 改法：贻笑大方；或被内行人笑话。

3. **津津乐道**：很有兴趣地谈论，不能说“津津乐道地谈论”。
   - 改法：津津乐道；或兴致勃勃地谈论。

4. **难言之隐**：难以说出口的隐情，不能说“难言之隐的苦衷”。
   - 改法：难言之隐；或难以说出口的苦衷。

5. **目前的当务之急**：当务之急已经含“当前最急”，不能再加“目前的”。
   - 改法：当务之急。

6. **浑身遍体鳞伤**：“遍体鳞伤”已经是全身都是伤。
   - 改法：遍体鳞伤；或浑身是伤。

7. **独自孑然一身**：“孑然一身”已经是孤单一人。
   - 改法：孑然一身；或独自一人。

8. **显得相形见绌**：“相形见绌”已经含比较后显出不足。
   - 改法：相形见绌。

9. **更加变本加厉**：“变本加厉”已经含程度加重。
   - 改法：变本加厉；或更加严重。

10. **一天天日臻完善**：“日臻完善”已经含一天天趋于完善。
    - 改法：日臻完善。

### 三、谦敬错位：只能自己谦称，不能拿去夸别人

1. **蓬荜生辉**：谦辞，表示别人到自己家或赠字画使自己家增光，不能说别人家蓬荜生辉。
   - 易错：我们参观了他蓬荜生辉的家。
   - 可用：您的到来使寒舍蓬荜生辉。

2. **抛砖引玉**：谦称自己先发表粗浅意见，引出别人高明见解，不能用于别人。
   - 易错：老师抛砖引玉，讲得精彩。
   - 可用：我先抛砖引玉，请大家补充。

3. **班门弄斧**：在行家面前卖弄本领，谦辞或贬义，不能拿来夸专业展示。
   - 易错：他在专家面前班门弄斧，赢得掌声。
   - 可用：在您面前谈书法，真是班门弄斧。

4. **一孔之见**：谦称自己的浅薄见解，不能称别人的意见。
   - 易错：老师的一孔之见让我受益。
   - 可用：这只是我的一孔之见。

5. **才疏学浅**：谦称自己才能不高、学识不深，不能直接评价别人，除非明显批评。
   - 易错：您才疏学浅，却讲得很好。
   - 可用：我才疏学浅，还请指正。

6. **绵薄之力**：谦称自己微小的力量，不能用于别人帮助自己。
   - 易错：感谢老师尽了绵薄之力。
   - 可用：我愿尽绵薄之力。

7. **鼎力相助**：敬辞，感谢别人有力帮助，不能用于自己。
   - 易错：我一定鼎力相助你。
   - 可用：感谢您的鼎力相助。

8. **高抬贵手**：请求别人宽恕或通融的敬辞，不能用于自己。
   - 易错：我对他高抬贵手。
   - 可用：请您高抬贵手。

9. **洗耳恭听**：谦敬色彩，表示专心恭敬地听别人讲话，不能用于别人听自己。
   - 易错：请大家洗耳恭听我的发言。
   - 可用：先生请讲，我洗耳恭听。

10. **敬谢不敏**：恭敬地表示自己能力不够，不能接受，谦辞；不是“感谢不敏捷”。
    - 易错：他敬谢不敏地完成了任务。
    - 可用：这个任务太重，我只好敬谢不敏。

### 四、大词小用：程度太重，普通小事压不住

1. **惊心动魄**：形容使人震惊、紧张到极点，不能用于普通小波折。
   - 易错：这次听写惊心动魄。
   - 可用：惊心动魄的救援。

2. **触目惊心**：看到某种严重情况而震惊，不能形容普通美景或普通缺点。
   - 易错：花园美得触目惊心。
   - 可用：污染现状触目惊心。

3. **叹为观止**：赞美看到的事物好到极点，不能用于坏事，也不能用于一般好。
   - 易错：他的错误令人叹为观止。
   - 可用：精湛表演令人叹为观止。

4. **蔚为大观**：形容事物丰富多彩，形成盛大景象，不能用于小规模事物。
   - 易错：我桌上的两本书蔚为大观。
   - 可用：各地民俗展演蔚为大观。

5. **铺天盖地**：形容声势大、来势猛、到处都是，不能用于少量事物。
   - 易错：几条消息铺天盖地。
   - 可用：广告铺天盖地。

6. **排山倒海**：形容力量强、声势大，不能用于轻微动作或普通情绪。
   - 易错：他排山倒海地走进教室。
   - 可用：掌声如排山倒海。

7. **石破天惊**：比喻文章议论新奇惊人，或事情惊人，不能随便形容声音大。
   - 易错：雷声石破天惊。
   - 可用：这个观点石破天惊。

8. **惊天动地**：形容声势或事业伟大惊人，不能用于普通小事。
   - 易错：他惊天动地地吃完早饭。
   - 可用：惊天动地的壮举。

9. **可歌可泣**：形容英勇悲壮的事迹值得歌颂，使人感动流泪，不能用于一般好人好事。
   - 易错：他每天按时交作业，可歌可泣。
   - 可用：英雄事迹可歌可泣。

10. **义愤填膺**：胸中充满正义的愤怒，不能用于普通生气。
    - 易错：作业太多，我义愤填膺。
    - 可用：听闻暴行，众人义愤填膺。

### 五、轻重错位：本来是严重负面，不能写普通缺点

1. **罪魁祸首**：造成严重祸害的首要人物或因素，不能用于普通原因。
   - 易错：没带伞是我迟到的罪魁祸首。
   - 可用：污染企业是当地生态恶化的罪魁祸首。

2. **恶贯满盈**：罪恶极多，已到受惩罚的时候，不能用于小错误。
   - 易错：他上课说话，恶贯满盈。
   - 可用：恶贯满盈的罪犯终被惩处。

3. **死有余辜**：罪大恶极，即使处死也抵不了罪，极重，不能乱用。
   - 易错：他考试作弊，死有余辜。
   - 可用：杀人元凶死有余辜。

4. **十恶不赦**：罪大恶极，不可饶恕，不能用于普通调皮。
   - 易错：这个孩子十恶不赦。
   - 可用：十恶不赦的罪行。

5. **令人发指**：使人愤怒得头发都竖起来，形容罪行极其恶劣。
   - 易错：他的字写得令人发指。
   - 可用：暴行令人发指。

6. **丧心病狂**：形容极端残忍、凶狠，不能用于一般不讲理。
   - 易错：他丧心病狂地多布置了两道题。
   - 可用：丧心病狂的犯罪行为。

7. **惨绝人寰**：人世间再没有比这更惨的，程度极重。
   - 易错：这次考试惨绝人寰。
   - 可用：惨绝人寰的灾难。

8. **灭绝人性**：完全丧失人的本性，极重贬义。
   - 易错：老板加班安排灭绝人性。
   - 可用：灭绝人性的屠杀。

### 六、语法搭配错位：词性和句法位置不对

1. **津津有味**：多作状语，形容吃或读、听、看时兴趣浓厚。
   - 易错：这本书津津有味。
   - 可用：他津津有味地读书。

2. **津津乐道**：常作谓语，后面一般不再接“地谈论”。
   - 易错：大家津津乐道地谈论。
   - 可用：这件事至今为人津津乐道。

3. **侃侃而谈**：形容说话理直气壮、从容不迫，主体应是人。
   - 易错：文章侃侃而谈。
   - 可用：他在会上侃侃而谈。

4. **夸夸其谈**：说话浮夸不切实际，贬义，主体一般是人。
   - 易错：这个方案夸夸其谈。
   - 可用：他夸夸其谈，却拿不出办法。

5. **娓娓道来**：形容人连续不倦地讲述，主体通常是人，不能直接说景物娓娓道来。
   - 易错：山水娓娓道来。
   - 可用：老人把往事娓娓道来。

6. **信手拈来**：多指写文章时能自由熟练地选用词句、材料，不能泛指随便拿东西。
   - 易错：他从桌上信手拈来一支笔。
   - 可用：典故在他笔下信手拈来。

7. **脱颖而出**：比喻人的才能全部显示出来，也可用于事物在竞争中显现优势；不能用于“问题暴露出来”。
   - 易错：环境问题脱颖而出。
   - 可用：他在比赛中脱颖而出。

8. **崭露头角**：比喻初显才能，多用于年轻人或新事物。
   - 易错：这位老专家崭露头角多年。
   - 可用：年轻选手崭露头角。

### 七、对象可用但方向错：不是不能用，是句子方向不对

1. **望尘莫及**：只望见前面人扬起的尘土而追不上，比喻远远落后。不能用于“很快追上”。
   - 易错：我终于望尘莫及地超过了他。
   - 可用：他的水平让人望尘莫及。

2. **望洋兴叹**：因力量不足或条件不够而无可奈何，不是看到海洋赞叹。
   - 易错：游客面对大海望洋兴叹。
   - 可用：面对高昂费用，他只能望洋兴叹。

3. **鞭长莫及**：力量达不到，管不到远处，不能理解为“马鞭很长”。
   - 易错：老师鞭长莫及地帮助了学生。
   - 可用：事情发生在外地，我们鞭长莫及。

4. **力不从心**：心里想做，但力量或能力不够。
   - 易错：他不想帮忙，所以力不从心。
   - 可用：他想继续工作，却力不从心。

5. **无能为力**：没有能力做到，语义比“力不从心”更直接。
   - 易混：和“不想做”混用。
   - 可用：面对突发情况，他一时无能为力。

6. **爱莫能助**：虽然同情、愿意帮助，但力量做不到；不能用于冷漠拒绝。
   - 易错：我懒得管你，爱莫能助。
   - 可用：我很想帮你，但实在爱莫能助。

7. **无可厚非**：没有什么可过分责备的，说明虽有问题但可以理解。
   - 易错：他的行为完全正确，无可厚非。
   - 可用：年轻人有自己的选择，无可厚非。

8. **无可非议**：没有什么可以批评指责的，程度比“无可厚非”更肯定。
   - 易混：二者不能随便互换。
   - 可用：他的处理公正合理，无可非议。

### 八、近义成语细差：中考选择题最爱卡这里

1. **骇人听闻 / 耸人听闻**
   - 骇人听闻：真实事情让人震惊。
   - 耸人听闻：故意夸大或捏造，使人震惊。

2. **不胫而走 / 不翼而飞**
   - 不胫而走：消息传播很快。
   - 不翼而飞：东西突然丢失、不见了。考试中重点区分：消息传开 → 不胫而走；东西丢了 → 不翼而飞。

3. **鱼目混珠 / 鱼龙混杂**
   - 鱼目混珠：拿假的冒充真的。
   - 鱼龙混杂：好人坏人混在一起。

4. **良莠不齐 / 参差不齐**
   - 良莠不齐：好人坏人混杂，或品质好坏混杂，偏质量。
   - 参差不齐：长短、高低、水平不一致，偏形态或程度。

5. **刮目相看 / 另眼相看**
   - 刮目相看：别人进步很大，要用新眼光看。
   - 另眼相看：用不同于一般的眼光看待，可褒可贬。

6. **绘声绘色 / 有声有色**
   - 绘声绘色：叙述、描写生动。
   - 有声有色：表现、活动生动精彩。

7. **身临其境 / 设身处地**
   - 身临其境：像亲自到了现场。
   - 设身处地：站在别人处境替人着想。

8. **耳闻目睹 / 耳濡目染**
   - 耳闻目睹：亲耳听见，亲眼看见。
   - 耳濡目染：长期听见看见而受到影响。

9. **休戚相关 / 息息相关**
   - 休戚相关：利害、祸福彼此相关，关系更重。
   - 息息相关：关系密切，范围更宽。

10. **耿耿于怀 / 念念不忘**
    - 耿耿于怀：多指不愉快的事萦绕心头。
    - 念念不忘：一直记着，可褒可贬。

11. **振聋发聩 / 震耳欲聋**
    - 振聋发聩：比喻言论使糊涂麻木的人清醒。
    - 震耳欲聋：声音很大。

12. **络绎不绝 / 连绵不绝**
    - 络绎不绝：人、车、船来往不断。
    - 连绵不绝：山脉、雨雪、思绪、声音等连续不断。

### 九、套题训练法：别让学生死背

1. **对象圈定法**：先问“这个词能修饰谁”。建筑、书籍、艺术形象、夫妻、学生、声音，先圈对象。

2. **褒贬打点法**：在题干旁边标“褒、贬、中”。凡是“趋之若鹜、始作俑者、处心积虑、弹冠相庆”进褒义句，先高度警惕。

3. **程度称重法**：把成语当砝码。普通小事压不住“惊心动魄、可歌可泣、惨绝人寰、令人发指”。

4. **字面刹车法**：遇到“差强人意、不刊之论、文不加点、万人空巷、七月流火”，先停，不按字面猜。

5. **重复删词法**：看到“忍俊不禁地笑、津津乐道地谈、目前的当务之急”，先查是不是语义重复。

6. **谦敬换位法**：把句子主语换成“我”和“您”试一遍。能不能自己说，能不能对别人说，常常一换就露馅。

7. **近义对照法**：不要让学生单背一个词，要成对背：不孚众望 / 不负众望，骇人听闻 / 耸人听闻，鱼目混珠 / 鱼龙混杂。

8. **造错句法**：每个成语故意造一个错句，再改对。比抄释义更有效，因为考试就是让学生在错句里识别裂缝。
