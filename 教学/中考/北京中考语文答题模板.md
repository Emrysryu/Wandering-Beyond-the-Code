# 北京中考语文答题模板

> 按试卷板块组织，覆盖全部题型。每个题型：常见问法 → 答题思路 → 答题格式（可直接套用）。答题格式用引用块标出。

---

## 一、基础·运用（12分）

北京特色：整个板块套在一个"任务情境"里（研学活动/展览讲解/公众号/班级活动），六道题共用同一段材料。**做非选择题时必须回看材料，确认答案对象与材料一致。**

### 1. 字音字形

| 判断方法 | 要点 |
|---|---|
| 多音字 | 先确定语境义，再定读音。常考："创/载/强/应/塞/曝" |
| 形近字 | 关注偏旁区别。常错："寒暄/喧""川流不息""再接再厉""脉搏/博" |
| 语境义 | 字典义对≠语境义对。先用自己的话说出语境义，再比对选项 |

**注意：** 一题常合并考字音+字义，字音看对了不要急着选，再验字义。

### 2. 词语/成语

| 陷阱类型 | 应对方法 |
|---|---|
| 对象错配 | 脑中挂两个标签——"能用于什么""不能用于什么" |
| 感情色彩 | 褒贬中性要与语境匹配 |
| 望文生义 | "不刊之论""差强人意""万人空巷"等需专门记忆 |

常考对象限定成语：

| 成语 | 限定对象 |
|---|---|
| 鳞次栉比 | 只用于建筑 |
| 琳琅满目 | 只用于物品 |
| 美轮美奂 | 只用于建筑/精美物品 |
| 栩栩如生 | 只用于艺术形象 |
| 络绎不绝 | 只用于人/车/船 |

### 3. 病句

六大类型速查：

| 类型 | 识别信号 |
|---|---|
| 搭配不当 | 主谓/动宾/主宾是否搭配 |
| 成分残缺 | 介词开头→缺主语；"使"字句→缺主语 |
| 语序不当 | 多个定语/状语的排列顺序 |
| 关联词误用 | 主语相同→关联词在主语后；主语不同→关联词在主语前 |
| 两面对一面 | "能否""是否""好坏"对应单面表述 |
| 句式杂糅 | 两种说法混在一起："原因是……造成的""围绕……为中心" |

### 4. 标点符号

| 易错点 | 规则 |
|---|---|
| 引号与句号 | 完整引用→句号在引号内；部分引用→句号在引号外 |
| 顿号vs逗号 | 并列词语用顿号；并列短语较长时用逗号 |
| 冒号管到哪 | 冒号管到句末句号，不能只管一半 |
| 破折号vs省略号 | 不能同时使用 |

### 5. 修辞判断

| 易混点 | 区分方法 |
|---|---|
| 比喻vs非比喻 | "像"字不一定是比喻。需满足：本体≠喻体，二者有相似性 |
| 比喻vs拟人 | 比喻有喻体，拟人无喻体（直接赋予人的动作/情态） |
| 借喻vs借代 | 借喻可还原为"A像B"，借代不可 |
| 排比vs对偶 | 排比≥3句，对偶必须2句 |

### 6. 语句补写（对联/排比/倡议/总结）

**形式约束检查法：** 动笔前把题干中所有约束用笔圈出，写完逐项核对。

| 常见约束 | 检查项 |
|---|---|
| 字数 | 数一遍，不多不少 |
| 句式 | 对偶→字数相同、词性对应、平仄相对；排比→≥3句、句式一致 |
| 内容 | 是否引用了指定材料/诗句；对象是否与材料一致 |
| 修辞 | 是否使用了指定的修辞手法 |

### 7. 关联词填空

先判断分句间的逻辑关系（并列/递进/转折/因果/条件/假设），再填词。**注意主语位置决定关联词位置。**

### 8. 书法字体辨认

| 字体 | 特征 |
|---|---|
| 楷书 | 方正端庄，横平竖直 |
| 行书 | 笔画连带，行云流水 |
| 草书 | 笔画省简，龙飞凤舞 |
| 隶书 | 蚕头雁尾，扁宽舒展 |
| 篆书 | 线条匀称，圆转对称 |

## 二、古诗文阅读（18分）

### （一）古诗阅读

#### 1. 默写填空

直接默写，注意易错字。**写完逐字检查，不写繁体、不写错别字。**

#### 2. 炼字题

**常见问法：**
- "某字好在哪里？请赏析。"
- "某字能否替换为某字？为什么？"
- "诗中最传神的是哪个字？请赏析。"

**答题思路：** 释义 → 描述画面 → 手法（如有）→ 情感

> **答题格式（常规型）：**
> "某"字意为……（释义），生动形象地写出了……的情景/状态（描述画面），运用了……手法（如有），表达了诗人……的情感。

> **答题格式（能否替换型）：**
> 不能替换。"某"字意为……，写出了……的情景/状态；而"某"字意为……，只能表达……。"某"字更能体现……的情感/意境，与全诗……的氛围更吻合。

**常用炼字术语表：**

| 词类 | 常见效果 |
|---|---|
| 动词 | 化静为动，生动传神 |
| 形容词 | 绘声绘色，细腻传神 |
| 色彩词 | 色彩鲜明，画面感强 |
| 叠词 | 增强韵律美，强化情感 |
| 数量词 | 精确/夸张，突出特征 |
| 拟声词 | 使人如闻其声，身临其境 |

#### 3. 意境/画面描述题

**常见问法：**
- "描绘了怎样的画面/意境？"
- "请用自己的语言描述某联的画面。"
- "这首诗营造了怎样的氛围？"

**答题思路：** 翻译诗句（展开想象）→ 概括氛围 → 情感

> **答题格式：**
> 诗歌描绘了一幅……的画面：……（用自己的语言翻译诗句，适当展开想象，加入修饰语）。营造了……的氛围/意境，表达了诗人……的情感。

**常用氛围词表：**

| 类型 | 氛围词 |
|---|---|
| 壮阔 | 雄浑壮阔、气势磅礴、开阔苍茫 |
| 优美 | 清新明丽、恬淡优美、明净绚丽 |
| 凄凉 | 萧瑟凄凉、冷寂孤清、凄清幽冷 |
| 闲适 | 恬静闲适、清幽宁谧、悠然自得 |
| 热闹 | 繁华热闹、生机盎然、欢快明亮 |
| 悲壮 | 苍凉悲壮、慷慨激昂、悲怆雄浑 |

**注意：** 描述画面时不能直接翻译，要展开想象加入合理修饰。概括氛围用四字词。

#### 4. 情感主旨题

**常见问法：**
- "这首诗表达了诗人怎样的情感？"
- "诗中蕴含了诗人怎样的思想感情？"
- "结合全诗，分析诗人的情感变化。"

**答题思路：** 结合内容（关键意象/词语）→ 指出情感 → 分条作答

> **答题格式：**
> 通过……（关键意象/事件/典故），表达了诗人……的情感。

**常见情感分类表：**

| 类型 | 具体情感 |
|---|---|
| 思乡怀人 | 羁旅之愁、思乡之苦、怀远之情 |
| 忧国忧民 | 忧虑时局、同情百姓、报国无门之悲 |
| 壮志未酬 | 怀才不遇、壮志难酬、功业未就之叹 |
| 田园闲适 | 归隐之乐、田园之趣、淡泊名利 |
| 送别之情 | 依依不舍、劝勉鼓励、豪迈洒脱 |
| 边塞征战 | 建功立业、戍边之苦、思乡之愁、战争残酷 |
| 咏史怀古 | 借古讽今、感慨兴亡、追慕先贤 |
| 咏物言志 | 托物言志、以物自况、高洁品格 |
| 爱情相思 | 缠绵悱恻、相思之苦、忠贞不渝 |
| 人生感慨 | 时光易逝、世事无常、乐观旷达 |

#### 5. 表达技巧/手法题

**常见问法：**
- "这首诗运用了什么表现手法？请简要分析。"
- "请从修辞/表现手法角度赏析某联。"

**答题思路：** 判断手法 → 结合诗句分析 → 效果/情感

> **答题格式：**
> 运用了……的手法（判断），写出了……（结合诗句具体分析），表达了……的情感/突出了……的特点（效果）。

**古诗常见手法速查：**

| 类别 | 手法 |
|---|---|
| 修辞 | 比喻、拟人、夸张、对偶、借代、用典、反问、互文 |
| 描写 | 动静结合、虚实结合、视听结合、远近高低、白描、工笔 |
| 抒情 | 直抒胸臆、借景抒情、情景交融、托物言志、借古讽今、用典抒情 |
| 表现 | 对比、衬托（正衬/反衬）、象征、以小见大、欲扬先抑、联想想象 |

#### 6. 名句赏析题

**常见问法：**
- "请赏析某句。"
- "某句历来为人称道，请分析其妙处。"

**答题思路：** 手法 + 内容 + 情感（三步走，与赏析题一致）

> **答题格式：**
> 这句诗运用了……手法/炼字精妙之处在于"某"字，写出了……的内容/画面，表达了诗人……的情感。

#### 7. 对比阅读题（北京特色）

**常见问法：**
- "两首诗都写了某意象/某主题，但情感不同，请分析。"
- "甲乙两诗在写法/情感上有何异同？"
- "两首诗中的某意象/某字含义有何不同？"

**答题思路：** 分别分析 → 找同 → 找异 → 扣题作答

> **答题格式（求异型）：**
> 甲诗通过……（意象/手法/内容），表达了……的情感；乙诗通过……（意象/手法/内容），表达了……的情感。两诗虽都写了……，但甲诗侧重……，乙诗侧重……。

> **答题格式（求同+求异型）：**
> 相同点：两首诗都……（共同的意象/手法/情感）。不同点：甲诗……，乙诗……。

**注意：** 对比阅读必须两首都分析到，不能只写一首。每首都要有"内容+情感"的具体分析。

#### 8. "一词领全诗"题

**常见问法：**
- "全诗围绕哪个字展开？请分析。"
- "某字是全诗的诗眼，请分析。"

**答题思路：** 指出诗眼 → 逐联分析如何体现 → 情感

> **答题格式：**
> 全诗围绕"某"字展开。首联……体现了"某"；颔联……体现了"某"；颈联……体现了"某"；尾联……体现了"某"。"某"字统摄全诗，表达了诗人……的情感。

### （二）文言文阅读

#### 1. 实词解释

三种方法：

| 方法 | 操作 |
|---|---|
| 扩词法 | 单音节→双音节："善"→"擅长" |
| 积累法 | 调用课内积累，如"走"→"跑"，"去"→"离开" |
| 推断法 | 根据上下文语境推断词义 |

> **答题格式：** 直接写出词义即可。注意词性要与原文一致。

#### 2. 虚词用法

重点掌握"之/而/以/其/于/为/乃/则"八个虚词的常见义项。

| 虚词 | 常见用法 |
|---|---|
| 之 | 代词（代人/事/物）；助词（的/取独/凑足音节）；动词（到） |
| 而 | 表并列/递进/转折/修饰/承接/因果 |
| 以 | 介词（用/凭借/因为）；连词（来/以至于）；动词（认为） |
| 其 | 代词（他的/那）；语气词（表反问/推测/期望） |

#### 3. 文言翻译

**六字法：对、换、留、删、补、调。**

| 方法 | 操作 |
|---|---|
| 对 | 逐字对应翻译 |
| 换 | 古今异义词替换为现代词 |
| 留 | 人名、地名、官名、年号保留 |
| 删 | 语气词、凑足音节的"之"等删去 |
| 补 | 省略的主语、宾语、介词补出（用括号标明） |
| 调 | 倒装句调整为现代语序 |

> **注意：** 关键实词必须翻译到位（往往是得分点），不能笼统意译。

#### 4. 内容理解与概括

> **答题格式：** （时间/地点），某人做了某事，结果……。用自己的话概括，不能照抄原文。

#### 5. 人物形象/评价

**答题思路：** 找事件 → 提炼品质 → 结合原文

> **答题格式：**
> 某人是一个……的人。从"……"（原文）可以看出他……（品质）；从"……"（原文）可以看出他……（品质）。

#### 6. 比较探究（课内外对比）

**常见问法：**
- "甲乙两文中某人的做法有何异同？"
- "结合甲乙两文，谈谈你对某话题的理解。"

> **答题格式：**
> 甲文中……（概括内容），体现了……；乙文中……（概括内容），体现了……。两文都表达了……（共同主题）。/两文在……方面有所不同：甲文侧重……，乙文侧重……。

## 三、名著阅读（5分）

### 1. 人物形象+情节

> **答题格式：**
> 某人是一个……的人。在……情节中（概括事件），他……（具体行为），表现出……的性格特点。

**注意：** 情节必须具体，不能笼统说"他很勇敢"，要有事件支撑。

### 2. 读书方法

| 方法 | 适用场景 |
|---|---|
| 圈点批注 | 精读时标注感受/疑问 |
| 跳读 | 快速了解情节发展 |
| 精读 | 关键章节细读品味 |
| 比较阅读 | 不同人物/作品对比 |
| 做读书笔记 | 摘抄好句+写感悟 |
| 专题探究 | 围绕某一主题梳理 |

### 3. 主题/启示

> **答题格式：**
> 这部作品通过……（核心内容概括），揭示了……的主题。我从中得到的启示是……（结合自身/现实谈体会）。

## 四、现代文阅读（23分）

### （一）非连续性文本阅读（约7分）

北京特色：多则材料组合（新闻+图表+评论等），考查信息整合能力。

#### 1. 信息提取与概括

**答题思路：** 审题确定范围 → 筛选关键信息 → 整合概括

> **答题格式：**
> 材料某某指出/表明……（用自己的话概括，不照抄原文）。

**注意：** 概括时合并同类项，不同角度分条列出。

#### 2. 图表信息转换

**答题思路：** 看标题→看项目→看数据→找趋势/比较→得结论

> **答题格式：**
> 从图表中可以看出，……（趋势/对比结果），说明……（结论）。

**注意：** 不能只罗列数据，必须得出结论。

#### 3. 材料比较/探究

> **答题格式：**
> 材料一侧重……，材料二侧重……，两则材料共同说明了……。

#### 4. 观点/建议/启示

> **答题格式：**
> 根据材料……的内容，我认为……。具体做法是：①……②……③……

---

### （二）记叙文/散文阅读（约16分）

#### 1. 内容概括题

> **答题格式：** （时间/地点），人物+起因+经过+结果。

**注意：** 语言简洁，不加修饰语。表格填空更要精炼。

#### 2. 词句赏析题（修辞/描写/句式）

**答题思路（四步法）：**

> **(1)** 运用了……手法/用了……词（动词/形容词/叠词等）
> **(2)** 写出了……内容
> **(3)** 表现了……（人物/事物/景物）的特点
> **(4)** 表达了……（人物/作者）的情感/主旨

**修辞赏析速查：**

| 修辞 | 答题模板 |
|---|---|
| 比喻 | 把……比作……，生动形象地写出了……的特点，表达了……的情感 |
| 拟人 | 赋予……以人的动作/情态，生动地写出了……，抒发了……的情感 |
| 排比 | 增强语言气势，有力地表现了……的特点 |
| 对比 | 将A与B对比，突出A……的特点，表达了……的情感 |
| 夸张 | 强调了……的特点，突出表现了……的情感 |
| 反问 | 加强语气，强调了…… |
| 反复 | 加强节奏感，突出表现了…… |

**描写赏析速查：**

| 描写类型 | 答题要点 |
|---|---|
| 人物描写（语/动/心/神/外） | 通过……描写，表现了人物……的心理/性格 |
| 环境描写（自然） | 渲染了……的氛围，烘托了人物……的心情 |
| 环境描写（社会） | 交代了……的背景 |
| 细节描写 | 细腻地表现了…… |
| 侧面描写 | 通过写……，从侧面衬托出…… |

#### 3. 句段作用题

| 位置 | 结构作用 | 内容作用 |
|---|---|---|
| 首段 | 总领全文/引出下文/设悬念/铺垫/伏笔 | 开篇点题/营造氛围/奠定基调 |
| 中间段 | 承上启下/照应标题或前文/推动情节发展 | 承接上文……，引出下文…… |
| 结尾段 | 总结全文/照应开头或标题/使结构完整 | 点明中心/深化主题/引人深思/出人意料又在情理之中 |

> **答题格式：**
> 结构上，……（选择对应的结构作用）。内容上，……（概括段落内容+情感/主旨）。

**注意：** 还需考虑是否涉及插叙、环境描写、表现手法等附加作用。

#### 4. 标题含义与作用题

**答题思路：** 表层义 + 深层义（象征义/双关义）+ 作用

> **答题格式：**
> 表层含义：……（字面意思）。深层含义：……（象征/双关/比喻义，指向主旨/情感）。
> 作用：①……②……（从线索/点题/悬念/双关/照应等角度选取）

标题常见作用：线索贯穿全文、点明中心、引发兴趣、双关义、交代对象/背景、照应结尾。

#### 5. 涵义理解题（词语/句子）

> **答题格式（句子涵义）：**
> 表层含义：……（句子字面义/"中译中"）。深层含义：……（主旨/情感/感悟）。

> **答题格式（一词多段出现）：**
> "某"字在全文中共同表达了……的情感。第x段中指……（语境义），表达了……；第y段中指……（语境义），表达了……。

**注意：** 如有前后对比，深层义要点出"以前……，现在……"的变化。

#### 6. 人物形象分析题

> **答题格式：**
> 某人是一个……（性格特点1）、……（性格特点2）的人。从……（事件/描写）中可以看出他……；从……中可以看出他……。

**注意：** 性格特点用四字词/短语概括；每个特点必须有原文依据。

#### 7. 环境描写作用题

> **答题格式：**
> 描写了……的环境/景象（概括内容），渲染了……的氛围，烘托了人物……的心情，为下文……做铺垫/推动了情节发展，暗示/表达了……的主题。

环境描写六大作用：①交代背景；②渲染氛围；③烘托心情；④推动情节；⑤暗示主题；⑥象征意义。

#### 8. 借鉴启示题

> **答题格式：**
> 文中……（概括相关内容），让我认识到……（道理/启示）。在生活中，我应该……（联系实际）。

## 五、议论文阅读（约10分）

### 1. 论点识别与补写

- **中心论点：** 看标题→看首尾段→概括分论点
- **分论点：** 看每段首尾句

> **补写格式：** 根据上下文逻辑关系，写出承上启下的概括句。注意与前后文衔接。

### 2. 论据分析与材料回归

**常见问法：** "下面的材料可以作为哪一段的论据？请说明理由。"

> **答题格式：**
> 我认为该材料x应放在第x段。该材料举了（引用了）……事例（的话），与第x段"……"的观点相符，材料y（另一则）只说了……，材料x更……。

**注意：** 三步缺一不可——①定论（放在哪段）②材料内容概括 ③与论点的对应关系。

### 3. 论证方法及作用

四种方法并列对比：

| 论证方法 | 答题格式 |
|---|---|
| 举例论证 | 举了……的事例，具体有力地论证了……的观点，进而论证中心论点，增强说服力 |
| 道理论证（引用论证） | 引用了……的话/名言，有力地论证了……的观点，进而论证中心论点，增强说服力 |
| 对比论证 | 将……和……进行对比，突出论证了……的观点，进而论证中心论点，使论证更鲜明 |
| 比喻论证 | 把……比作……，生动形象地论证了……的观点，进而论证中心论点，使深奥道理浅显易懂 |

### 4. 论证思路/过程分析

> **答题格式（先观点后举例）：**
> 第x段先提出……的观点，接着举了（引用了）……的事例（的话）进行论证，最后得出……的结论。

> **答题格式（先举例后观点）：**
> 第x段先列举了……的事例，由此引出……的观点。

### 5. 语句推进论证分析（北京特色）

这是北京中考高频题型，常从三个角度切入：

**（1）问手法（设问/反问）：**

> **答题格式：**
> 该句运用了……（设问/反问）的方法，由上文关于……的论述，转换到下文关于……的论述，推进了文章论证。

**（2）问词语（"另一方面""从更大范围看"等）：**

> **答题格式：**
> "某词"转换话题，由上文关于……的论述，转换到下文关于……的论述，从而更全面地论述了本文观点，推进了论证。

**（3）问关联词（"只有……才能……进而……"等）：**

> **答题格式：**
> 首先使用"……"说明……是前提/条件，其次使用"……"说明在上述条件下会产生……的结果，最后使用"……"强调……（进一步的效果），层层推进，论证了……的观点。

**（4）问"首先/其次/再次"的逻辑：**

> **答题格式：**
> "首先"论述……，这是首要的/根本的；"其次"论述……，是在前者基础上的深化；"再次"论述……，是更高层面的要求。三者遵循从……到……的逻辑顺序（从主要到次要/从内容到形式/从个人到社会等），使论证层层深入。

### 6. 开头段作用

> **答题格式：**
> 开头引用了……/举了……的事例/讲述了……的故事，引出本文……的论题/论点，激发读者阅读兴趣，同时作为……论据论证了……的观点。

## 六、作文（40分）

### 命题/半命题作文审题要点

| 步骤 | 操作 |
|---|---|
| 圈画关键词 | 题目中的限定词（时间/地点/对象/范围）全部圈出 |
| 确定立意 | 关键词背后的深层含义→确定中心思想 |
| 选材 | 选最熟悉、最有细节的素材，以小见大 |
| 拟提纲 | 开头点题→中间2-3个段落展开→结尾扣题升华 |

**常见失分点：**
- 跑题（忽略限定词）
- 记流水账（缺少细节描写）
- 主题不明（结尾不扣题）
- 字数不足或严重超出

### 想象文写作要点

| 要求 | 要点 |
|---|---|
| 合理想象 | 基于现实生活的合理延伸，不能天马行空 |
| 细节真实 | 想象中仍需要有具体的环境、动作、语言描写 |
| 主题明确 | 想象是手段，表达思考/情感才是目的 |
| 结构完整 | 有起因、发展、高潮、结局 |

## 附录：答题通用规范

### 1. 审题规范

- **圈画法：** 用笔圈出题干中的限定词（"结合全文""简要分析""某段""两点"等）
- **问什么答什么：** 问"作用"不要答"含义"，问"赏析"要有"手法+内容+情感"
- **注意分值：** 2分通常答2点，3分通常答3点

### 2. 分点作答规范

- 多点作答用①②③标序号
- 每点一个角度，不重复
- 先总后分，先主后次

### 3. 字数控制

- 简答题：紧扣要点，不写废话
- 开放题：一般3-5句话
- 作文：不少于600字

### 4. 术语使用规范

- 用学科术语，不用口语（"写得好"→"生动形象"）
- 修辞手法、描写方法、论证方法的名称要准确
- 情感词要具体（"表达了感情"→"表达了对……的思念之情"）
