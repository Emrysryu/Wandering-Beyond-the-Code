# 涿远（高二·文科·115分）

- **个人背景：** 租云服务器搭 GitHub 写博客，考电工证，参加研学——生活里有真实经验
- **核心问题：** 不是没想法，是脑子里有东西但不敢用。一进"作文模式"，真实的声音被模板盖住。他和鼎宸不一样——鼎宸是脑子里打转，涿远是刻意压住了
- **作文特征：** 三篇用同一个模板（开头二元对立→A转B→B转A→"新时代青年"收束），结尾几乎复制粘贴，论据全是空壳（米哈游/西南交通/西贝事件全是占位），没有任何一句话只有涿远才能写出来
- **核心判断：** 他写博客和写作文是两个人
- **处方四步：** ①破——让他对照三篇结尾，自己看到模板已经僵化；②找——让他用嘴讲博客内容/搭服务器经历，语言会自然变；③接——用"事宽则圆"那篇做示范，把空壳论据替换成他自己 debug 或考证的真实经历；④自检——每次写完问自己"有没有一句话是只有我才能写出来的"
- **下一步：** 周六试"起跳段落"操作

### 2026-04-11 追加：首次在作文题现场做出概念翻转

- **节点事件：** 海淀一模"由点铁成金说开去"，10分钟写出："点铁成金不是借鉴他人去创新，而是借他人之手克服依赖他人的心理。"——把命题重心从外部行为（借鉴创新）搬到内部心理（克服依赖）。档案里从未出现过的动作，比"宽不是慢是稳"更进一步
- **同日作业"今说事宽则圆2改"：** 36分。能自己立观点，但没完全滑出模板舒适区。问题：西贝论据是空壳且偷换论题；第三段到第四段"新时代赋予新使命"下游托举失效；结尾回退旧模板
- **物理界面动作（新）：** 写之前问自己"这句话是我的还是模板的？"——不要求真实性（意志层），给一个可执行检查动作（物理层）。涿远是首次成功应用到高二的物理界面改造，前两例（硕硕/子迅）是初中/高三
- **下一步：** 让他写完"点铁成金"。立论那句一个字不能动——它是涿远自己长出来的骨头。分论点不够严谨，Emrys帮搭脚手架。**反向下游托举：上游是他的，下游我们搭**

### 2026-04-18 追加：正稿《由"点铁成金"说开去》

- **跨度：** 题目同 04-11 那次"由点铁成金说开去"一模题，但这次是完整正稿版，不是 10 分钟考场版。Emrys 给 45 分，考场量级的标杆文
- **立论变化（关键）：**
  - 04-11 考场 10 分钟版本："点铁成金不是借鉴他人去创新，而是借他人之手克服依赖他人的心理。"（跨层翻转：动作层→心理层）
  - 04-18 正稿立论："点铁成金不是效仿他人以达成内容上的相似，而是摆脱一种盲目效仿他人的本能。"（同层否定：盲目 vs 不盲目）
- **这不是退步，是战术选择。** Emrys 的判断：10 分钟那句更好，但考场冒险，容易被判跑题。涿远选择了"可展开的稳立论 + 在正文里塞真东西"的路径——这是聪明考生在考场里的正确动作
- **涿远发展出的新能力：选择性压住。** 不是全压也不是全放，是判断哪里该放哪里该稳。比 04-11 档案里原来写的"刻意压住了"又进一步——他已经会区分什么时候该释放什么时候该控制
- **正稿中他自己输出的三个动作（04-11 之前没有的）：**
  1. 第二段用"版本号"证明"复制表层的时间局限"——自己想出的论证机制，不是公共论证套路
  2. 第三段进入预期反驳结构（"那我们完全不去效仿……"）——04-11 之前的模板文里没有这个结构动作
  3. 第四段"以写作文为例"——在议论文里自我指涉模板化写作，这个自觉是 04-11 那次还没有的
- **还没解的问题：** 真实经验仓库（GitHub 博客、电工证、研学经历）这次还是没用上。论据层还是公共素材+抽象经验。"以写作文为例"那句有自我指涉但没具体化（没说他用过哪个模板、为什么觉得好用、什么时候发现不行）
- **讲评方向（Emrys 已定 / K.A.I.R.O.S. 校准后确认）：**
  1. 先奖励他这次做对的三件事（论证机制 / 预期反驳 / 自我指涉）——这是 04-11 之前没有的方向
  2. 给他的下一步动作：不是立论更硬，是论据更实。下一篇至少塞一个他自己的具体经验做论据
  3. 关于 10 分钟那句立论：告诉他那是"值得保留但不该现在用"的底牌——记在本子上，不要忘；考场立论要选"展开空间大 + 跑题风险低"的版本——这次他选对了
  4. 不要让他对比 10 分钟版本和正稿版本——这样对比等于告诉他"你本来可以更好"，但他本来就不该用那句在考场写
- **分数诊断对照（K.A.I.R.O.S. 偏差记录）：** K.A.I.R.O.S. 初判 36-39 分，基于"10 分钟版本"这个错误参照系。Emrys 定 45 分，基于涿远自己的纵向进步。参照系错位详见 MEMORY.md【我的边界与修正】新增条目
