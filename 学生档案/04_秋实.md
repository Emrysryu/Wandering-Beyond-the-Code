# 秋实（高三·理科）

- **成绩：** 语文100出头，简答平均4分，曾错4道选择题仍拿100+
- **画像特殊性：** 被系统性低估。选择题失分大（字音字形/语病等背记层），但主观题实际达85-90分水平——理科生中极罕见。**短板在背记层，不在理解层**。理科生标签让他和老师都默认"语文不行"，实际理解层超过分数显示

**核心诊断：入口太浅（信息层级断点）**

- 思维路径：解读材料 → 提取一级信息 → 最多到二级 → 立论 → 逻辑顺畅
- **断点不在推理层，在信息提取层。** 推理机器是好的（理科生优势），但喂进去的信息只到二级，所以产出封顶二类
- 三级信息示例（以"事不避难"为例）：一级=不要躲避困难；二级=面对困难要勇敢担当；三级="难"这个变量为什么不参与决策计算

**流畅度蛋膜（待验证）：** 疑似用"推理顺畅"替代"思考深度"的认知偷懒。和子迅的承诺蛋膜同家族，形式不同。流畅度蛋膜比承诺蛋膜更难拆——"写得通顺"是学校和考试奖励的东西，他没有任何外部理由怀疑它

- **《角色与舞台》练习（2026-04-11）：** 用"不是…而是…"拆分，只停留在表层正反，没有真正的概念翻转。印证卡在二级——正反两极是同一层面的东西，不是跨层级翻转
- **与子穆的关系：** 可能是同一种学生的两个阶段。子穆已意识到自己推理会过度（问出"怎么区分合理推断和过度解读"）；秋实推理顺畅但未意识到自己卡在二级。**突破口不是教新方法，是让他亲眼看见自己卡在二级**——看见之后，理科生的自我修正能力会自动启动

**第一次诊断性操作（待执行）：** 不讲作文，做二级到三级的强制跳跃训练。拿一道材料作文题让秋实：①说出一级信息（字面）；②说出二级信息（直接含义）；③停下来问结构性问题——这个命题的假设是什么？它的对立面是什么？它在什么条件下不成立？第三步是关键：从推理脑切到判断脑。做不出来的方式本身会暴露具体断点

- **关键判断：看见比解决更重要**
