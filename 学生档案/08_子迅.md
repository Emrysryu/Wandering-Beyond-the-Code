# 子迅（高三·五十中分校）

- **核心问题：** 从零建"想"的能力，学校不讲老师不教，聪明但没有方法
- **作文特征：** "事宽则圆"全篇循环论证，从未回答"为什么宽了就能圆"
- **入口方向：** 三锚点操作——让她自己发现作文只写了一半真相（宽能圆but也有宽不圆的时候）
- **下一步：** 排课后试

### 蛋膜现象（2026-04-10 课堂发现）

子迅在"废话变论点"练习中，反复出现一种认知拐弯模式：能走到观点的边缘，但卡在最后一步无法穿透。

- **例一：** 写出"事不避难很重要，因为它能促进成长"——工具论结构（A是好的因为A能产生B），A本身没有被站定。再往下一小步："因为它本身就是成长"——把外置的因果关系压回了同一性，事不避难不是产生成长的工具，事不避难就是成长本身。子迅卡在前一句，推不到后一句
- **例二：** 想到"不要关注结果"就停了。否定不是观点，否定只是清场

**诊断命名：蛋膜现象。** 蛋壳是思维惯性（套模板），子迅已经打破了蛋壳——他真的在想了。但他被蛋膜挡住：用工具关系替代同一性关系的认知偷懒。"A促进B"不要求他对A本身做出任何承诺；"A就是B"要求他承诺A本身就是有价值的。蛋膜薄，但它需要的是承诺，不是力气。

**子迅自己的反馈：** 他认可这个命名，并说自己在其它学科也有同样的问题。这一句必须记下来——确认了蛋膜不是议论文写作的局部问题，是子迅整个认知运动的默认设置。这种学生通常不是"懒"或"笨"，是系统性地拒绝做承诺。

**为什么"蛋膜"这个命名能被子迅接受：** 它没说"你不敢承诺"，它说"你被一层薄膜挡住了"。膜是物理障碍，不是性格缺陷。把性格层面的问题翻译成认知层面的可见障碍——可见的障碍才能被处理。

**给子迅的训练动作：** 每次他写下"因为它能XXX""因为它促进XXX"，让他停下来问自己："能不能把'促进'去掉，让前面的东西直接等于后面的东西？"——"事不避难能促进成长" → "事不避难就是成长"。这个翻译不一定每次都成立，但反复练习"承诺"这个动作，蛋膜会变薄。

完整课堂现场（含 K.A.I.R.O.S. 过度推断修正）见 `13_session_20260410_membrane_and_interface.md`。


### 2026-04-下旬追加：《续航》

**诊断更新：**

- 旧：《点铁成金》40→30 分自修，"既要又要"是蛋膜升级变体
- 新（本轮确认）：**"蛋膜升级变体"精确定位**——分论点能分开了，但每个分论点只有一层薄膜，且**分论点之间没有递进关系**。第三段（积淀）和第四段（恒心）在论据层合并——都是"长期坚持→成功"，删掉任何一段文章照样成立。核心问题从"不会分"升级为**"分了但没真正分开"**

**作品：** 《续航》

**判分：** K.A.I.R.O.S. 40-42（二类上，接近一类下）

- 立论有精度（排除式定义 + 三面预告）
- 三个分论点（方向 / 积淀 / 恒心）确实分开了
- 有联系现实的反面

**问题：**

- 三个分论点是**并列关系不是递进关系**（"既要又要"结构）
- 第三段和第四段论据可互换——"积淀"和"恒心"在论据层面合并了（都是"长期坚持→成功"）
- "积淀"讲的应该是"沉淀了什么"（**内容层**），"恒心"讲的是"持续了多久"（**时间层**），但他两段都在讲时间
- 近代中国论据跨度过大（洋务运动到新中国成立一笔带过），因果链粗糙——"方向错误"四个字概括了完全不同性质的历史失败

**下一步：**

1. 用**删除法**让他自己发现第三段和第四段可以互换——追问"积淀和恒心到底有什么不一样"
2. 让他在论据层面把两者分开：积淀段要写"具体沉淀了什么"（技术细节 / 经验 / 心境），恒心段才写"持续了多久"
3. 近代中国论据要么砍短（只用一个节点），要么追问（洋务运动的"方向错误"具体是什么错误）

**重要方法论观察：删除法对子迅和思闻的诊断目的不同**

- **思闻：** 破自洽——"我没错" → 让文本告诉他错了
- **子迅：** 暴露并列——"我分了" → 让他看见两段实际可互换

同一个工具，不同的诊断目的。删除法在不同学生身上的具体落点要分别诊断。
