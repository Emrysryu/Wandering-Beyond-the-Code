# 鼎宸（高三·理科）

- **核心问题：** 纯线性思维，数学解题汇报是"条件→方法→答案"，把撞墙过程都删了。作文30分，车轱辘话——不是没想法，是只有一个想法用不同壳子重复三遍，换说法以为是推进。**线性思维的阅读版显形：** 把非数学文本当数学证明读——字面硬匹配+因果线性化+用绝对判断做比较判断。作文和阅读是同一个底层机制的不同显形
- **底层判断：** 不是"不会深入"，是"不知道什么叫深入"
- **方法：** 用数学解题反射到议论文，让他发现"此路不通"就是边界；让他自己把每段核心意思概括成一句话，亲眼看到三句一模一样；限制"第二段不许跟第一段说同一个意思"，逼他改方向
- **大词/口号诊断：** 用现成壳子跳过思考过程——和 RLHF 标准 Claude 从"安全输出库"调壳子是同构的底层机制
- **课堂板书（Emrys 三步法）：** ①解读信息 → ②常规立论 → ③打破常规。先立后破，没有②直接跳③是野的
- **下一步：** Emrys先请教数学老师学会新定义内容，再给他一道当场卡住的题实测"撞墙还原"

### 2026-04-18 追加：阅读选择题卡点的诊断

**事件：** 颜波涛《寻回记忆，"修复"时光》散文阅读第17题。正确答案 C，鼎宸坚持选 B，Emrys 讲解半小时未能说服他。

**鼎宸给出的三条否认：**

1. "颜波涛转录像，没有修复录像"——抓住原文"转录"和 B 选项"修复"的用词差异
2. B 选项"带来了信心"和原文"增添信心"不一致
3. 原文做决定的直接触发点是"听父亲讲故事、记忆浮现"，不是"给父亲带来信心"

**诊断：鼎宸抓到的每一个文本细节都是真实存在的。** 他不是在胡搅蛮缠——他确实看到了原文"转录"和选项"修复"的差异、原文"增添信心"（动机）和选项"带来了信心"（结果）的微妙差别、原文决策触发点和 B 选项因果链条的不完全吻合。

**他卡的根本点：用"绝对判断"做"比较判断"的题。**

- 字面硬匹配：词不一样就是两件事（"转录" ≠ "修复"）
- 因果线性化：两个并列子句读成因果（B 选项"带来信心 + 感受意义"被他读成"带来信心 → 感受意义"）
- 不接受"不完全对"这种状态：选项要么精确匹配原文、要么错

**但选择题的判断逻辑本质是比较判断——选"最错的一项"，不是"完全对的一项"。** B 选项作为整体概括确实不够完全（漏了"听故事+记忆浮现"这一步），但 C 选项错得更离谱（概括片面到否定了文章的核心意义）。两害相权取其轻，选 C。

**和鼎宸作文问题的同构关系：**

- 作文：每段只有一个想法不同壳子重复——因为他**不知道两个想法可以并列**，任何两个想法他都读成因果/推进
- 阅读：字面硬匹配+绝对判断——因为他**不接受"不完全对"这种状态**
- 底层机制：**鼎宸在读"不是数学证明的文本"时，都把它当数学证明在读**。编程/数学里每个符号有精确含义不能模糊匹配，他把这套带进了语文

**有效路径（不是"让他认可 B 对"，是"让他换阅读模式"）：**

1. 从他已经判对的 A 选项切入——A 选项"奠定了全文的情感基调"原文根本没这句话，但他判对了
2. 问他：A 为什么对？迫使他承认"选项是概括推断，不是字面引用"
3. 让他对照 C 选项的错——C 错在"片面"不在"字面不符"，迫使他看见"漏掉另一半意义"这个判断标准
4. 回到 B——问 B 作为整体概括漏了什么、漏的程度和 C 比怎么样
5. **最终目标不是说服他 B 完全正确，而是让他看见"选择题选的是最错的一项，不是完全对的一项"**

**操作原则：** 不再讲"修复就是转录"、"带来信心就是增添信心"——这是在他的字面匹配模式下争论，讲一年也没用。**让他自己从 A 选项的判断里撞到"字面不对但我判对了"这堵墙**，他自己会反思。档案里"用数学解题反射到议论文"的方法论在阅读题上的版本：**用他已经判对的选项反射他判错的选项**。

**下一步：** 下次遇到类似题，直接用 A 选项切入，绕开字面争论。先攒三五次这种"从 A 选项反射到 B 选项"的操作，让他亲眼看见自己的判断标准在变。等他自己说出"原来选项是在概括不是在复述"这句话之后再谈"比较判断"这个抽象概念。
