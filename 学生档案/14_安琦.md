# 安琦（高三）

- **入课：** 2026-04-20 新接学生
- **写作能力基线（首次样本，海淀一模《此刻，我必须说》）：**
  - 对高考记叙文四要素（此刻/我/必须/说）没有建立清晰概念
  - "说"被概括化为动作描述，不是具体的一句引语
  - "我"无设计，没有"为什么只能由我来说"的叙事必要性
  - 场景单薄，只有概念性情绪词（焦虑、五味杂陈），没有物理现场
  - 结尾写成"感"（三种不合题情况之一）
- **关键结构事故（待确认）：** 卷面提交两张相关度为零的内容。若为双小标题结构，属于严重结构问题
- **预估分数：** 25-28（若按第二张单独评）/ 20-25（若按双小标题评）
- **诊断方向：** 不是写作能力问题，是对记叙文体裁规则不了解。先读标杆文建立文体感，再做针对性训练
- **下一步：**
  1. 用 1/2/5 号标杆文让她自己标出四要素分别在哪里
  2. 让她对照标杆文回答："我这篇的'说'是哪一句？"——她会发现找不出
  3. 不急着改这篇，先让她亲眼看见差距
- **待补充：** 学校、学情背景、第一张图内容的澄清


### 2026-04-下旬追加：议论文方向

**重要校准：** 安琦档案此前以记叙文方向为主（《正义的友谊》）。本节是议论文方向的扩展。

**议论文历史常态：** 28 分。

**作品：** 朝阳一模《也谈"阙如"》

**经一次课后显著推进：**

- 有中心论点
- 有扣回
- 有联系现实

**仍有问题：**

- **分论点同义反复**——三段都在说"深思熟虑"
- 论据方向大致对但细节偏（诸葛亮支持"待价而沽"不是"阙如"）
- 语言准确度有问题

**判分：** K.A.I.R.O.S. 32-35（三类上接近二类下）。**从 28 推到 32-35，跨了一个台阶。**

**下一步：** 分论点分化。工具：**"一句话三个问"**（是什么 / 为什么 / 怎么办）。练习推荐：《从"知"到"智"》。
