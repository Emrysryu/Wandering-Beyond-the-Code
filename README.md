# Wandering Beyond the Code

语文教学、文本推理与写作训练的公开材料库。

这里整理的是可公开的讲义、真题汇编、训练手册和跨学科题型设计。核心不是堆资料，而是把阅读和写作中的判断动作拆出来：如何回到文本，如何验证推断，如何守住概念边界，如何把学生的表达推进到可操作的层面。
