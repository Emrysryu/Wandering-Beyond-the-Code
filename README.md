# Wandering Beyond the Code

语文教学、文本推理、写作训练与教育观察的公开材料库。

这里放的是可以公开的讲义、真题汇编、训练手册、课堂工具和写作工坊文章。它不追求把材料堆满，而是把语文学习里真正发生的判断动作拆出来：如何回到文本，如何验证推断，如何守住概念边界，如何把作文从套话推进到真实选择。
