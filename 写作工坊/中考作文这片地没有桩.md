# 中考作文这片地，没有桩

今天这一年做的两个小工具并排摆进去——一个中考语文基础题库，一个高考文言小题生成器。摆完盯着看了一会儿，一个念头硌了我一下：中考那个，题域明明看起来更"基础"，做起来却比高考文言难得多，硬伤一堆。

一开始我以为，是中考基础题型太杂——成语、病句、标点、对联、仿写，八种，每种脾气不一样，自然难。后来发现不是。题型杂只是表皮。

得先说清楚一件事：底下这些话，不是我一个人在书房里想出来的。今天我把两个项目的来龙去脉跟 K.A.I.R.O.S. （Claude Opus 4.7）从头过了一遍，结果从"哪个项目更难写"这种小事，一路聊到了中考评价的根上。这一篇，是那场对话留下的东西——我和它来回拆、来回纠，咬出来的。中间它有两次顺着分析往下滑、滑过了头，被我按了回来；"桩""赝品评标"这些说法，也是聊着聊着才长出来的。所以它不是一条推导干净的思路，更像一段对话散场后留在桌上的渣。我把渣留着，没去磨平——磨平了，就看不出它是怎么一步一步走到末尾那个"呵呵"的了。

真正的事，得从"高考死板吗？"这个问题钻进去。

我们常说高考死板、中考无序。可高考真的死板吗？我自己今年已经出过三套高考模拟卷，那个手感很清楚：客观题，特别是文言文的客观题，改两遍就锁死了，对错有地方可锚；可作文题、散文阅读、古代诗歌鉴赏的主观题，参考答案我来回掰了多少轮——那一刻我在干什么？我在凭空造一个"出题人想要的意思"，我自己就成了那个意思的源头。

所以高考不是均匀地死板。它是一张拼贴的卷子：一半硬边界（文言、默写、客观选择），一半软边界（作文、文学类阅读）。它在该硬的地方硬，在作文那种地方，它一点都不硬。

想清楚这个，中考的病才显出来。

中考的病，从来不是"软"。作文本该是软的——课标白纸黑字写着"以我手写我心"，要的就是真实。作文软，是它该有的样子。中考的病是另一件事：它把软的东西，塞进硬的壳里。病句题，判定本来是一桩软的语感判断，可它给你 ABCD 四个选项，长着一张和文言实词题一模一样的、"有唯一硬解"的脸。作文呢，本来最软，到了初三，被教学硬塞进五段式、句句点题的模子里。

软，不是病。软得不诚实，才是病。

不诚实软到什么程度，是能测出来的。这两年我带过二十多个中考生。同一篇中考作文，换一个老师判，分数能直接差出3～4分。高考不是这样——高考作文换人判也有出入，但至少落在同一个档里，上下不会差过3分。有人说高考分值大、3分不显，对，可比例摆在那：中考100分的盘子里飘4分，是高考150分盘子里飘3分的两倍还多。

为什么高考飘得住，中考飘不住？

因为高考有桩，中考没有。

高考作文有评标。那评标的描述其实也很"感觉化"——"立意新颖""语言得体"，没法量化。但它有一件硬东西：它在一团软判断里，楔进了几个半离散的脚手点。能不能解读出n组概念、有没有对当下的论述、立意高不高、语言得不得体——这些不是分数，可它们是能争、能收敛的东西。两个阅卷人意见不合，他们能吵的是一个具体的点："他到底算解读出两组还是三组。"吵着吵着就靠拢了。桩，就是让分歧有地方落脚的那根东西。

中考没有桩。两个中考老师判同一篇，他们没东西可吵——没有命名好的检查点，就只能各自退回自己的私人语感，然后各报一个数。那4分的飘，不是中考老师不专业，是他们脚下没有桩可踩。

而真空，是会被填的。学校总得教点什么，总得有个出了事能甩锅的抓手。于是教学这头自己造桩——五段式、每段点题、开头结尾扣题。可自己造的桩，只可能造成形式，造不成内容。因为"什么是好立意"这种内容标准，本该考试方给，考试方没给。三段还是五段、点没点题，数得出来；至于神，没人给过它桩。

所以五段式是一套赝品评标。它把脚手点立在了唯一一处不需要标准就能检验的地方：结构。它从被发明的那天起，就注定只有形，没有神。

往下还有一层，是文体。

中考考记叙文，高考（北京卷）作文议论文记叙文二选一。议论文天生好给桩——论证是讲道理，道理能拆成概念、能拆成有没有回应当下，接近可数。记叙文难。"故事张力"这种东西，听起来根本没法下桩。

可它能。我自己做过一份《故事设计讲义》，英雄之旅、两难之选、事件的价值转化——这些就是记叙文的桩。这个困境是不是一个真两难、这一笔有没有一次真的价值翻转、人物到底有没有做出选择——都是接近"有 / 无"的检查点。它们不像"三组概念"那么硬，但一样能争、能收敛。

所以记叙文不是没有桩。是记叙文的真桩——张力结构——比议论文的桩更难被看见，于是更容易被赝品桩整片整片地替换。硬点题，就是记叙文的赝品桩。它和五段式同源：检验性强、数得出来，所以偷懒的时候默认抓它。可点题根本不是一篇记叙文好坏的来源。

写到这儿，本该顺势收一个亮的尾：那就把《故事设计讲义》用到中考上，把真桩给初中生。

可这条路是堵死的。那份讲义是给高中的。初中用不了——学校不认，考场不认。理由是：他们认为初中生没有这种多维度的情感与主旨鉴赏能力。

呵呵。

把这句话翻过来看。"初中生没有这种能力"——它不是一个关于十五岁大脑的判断，它是一张许可证。只要这句话成立，评价方就不必为记叙文建真桩，不必训练阅卷人，不必承担那个会变大的飘。"他们写不动"，是"我们评不动"的体面替身。一个评价系统的能力缺口，被重新贴了一张标签，贴成了孩子的天赋缺口。锅甩到最后，扣在十五岁的人头上。

更糟的是，这句话会自己把自己变成真的。系统说初中生没有多维鉴赏力，于是不给真桩、不教、不考，于是大部分初中生确实没长出来，于是正好印证了那句话。"能力不足"不是这个闭环的前提，是它的产物。

我也有学生每次作文能拿到38分，写的是真情吗？是。那是我教得好吗？不是。我能调整的只有结构，其事之目见耳闻我替代不了。这时候大概所有人都会把她的能力归为“天赋”吧？于是她成了那个“不需要教”的少数派。没错，但有天赋又不止于天赋，因为“天赋”一出，就等于否认了她后天的思考和能力。于是系统的能力缺口就成了"大部分孩子写不动"。

我那份讲义在这里反倒成了一件碍事的证物——它证明了记叙文的真桩造得出来。桩就摆在那儿。"初中生没能力"现在缺的根本不是孩子的能力，是一个肯把桩放下去的考场。

最后这一格最冷，它落在我自己的学生身上。我要真在课上教一个中考生去经营故事张力、教他别硬点题——我可能是在亲手压低他下个月的中考分。因为他要走进的那个考场，认的就是点题。在初中这一段，教真东西，和考好那张卷，是冲突的。

这篇就停在这儿。我没有一个体面的收尾，也不打算造一个。一个十五岁的人坐在考场里，写一篇本该"以我手写我心"的作文，而判他的那套尺子——既看不见、又会飘、还在源头上就认定他写不出“心”。我把这件事如实记在这儿。

完。
